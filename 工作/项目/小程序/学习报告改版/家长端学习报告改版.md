## 项目概述
儿童学习 APP 配套的家长端 APP，主要功能为呈现孩子学习数据，帮助家长了解学习效果，展示课程专业性，建立信任关系，促进续费转化。当前包含"学习报告"、"学习安排"、"家长中心"、"我的"四个一级页面，本次优化聚焦"学习报告"页面。

项目旨在优化页面信息结构和视觉风格，解决当前版本存在的专业性不足、逻辑关系弱、信息冗余、重点不突出等问题，提升家长对学习效果的感知和课程信任度，促进续费转化。

（备注：我们的有课程、课包、课时三个层级，课程如阅读、思维、美育，每个课程下可能有多个课包，例如阅读 L 1 全年系统包、阅读 L 2 体验包，每个课包下，在单日大部分情况只有一个课时，但可能会存在多个课时，日报是课时维度的，若存在多个课时，就会有多个日报）

### 核心问题
1. **整体感觉**：整体产品（这里主要指的是页面感觉和重点信息）呈现出来的"计划专业性"不强，显得过于"好耍"。就像我们想要的是一个严厉且活泼的老师，但这里呈现出来严厉不足，活泼有余。

2. **逻辑性**：年度计划和日报，阶段报扣得不紧密，逻辑关系不强

3. **信息呈现**：和上面问题相关。页面内容多，繁杂。重点信息不突出。

4. **家长参与度**：家长端不应该仅仅是数据看板，更是家长与孩子之间建立连接、家长与品牌产生信任的桥梁。当前页面缺乏对家长的行动指引

## 过程记录

### 🗓️ 2025-09-25 报告优先级与内容定位讨论

**背景**: 讨论日报、阶段报、月报的优先级关系和内容定位

**ui观点**:
- **阶段报更关键**: 周期性数据具有对比价值，能更好体现学习效果和课程价值
- **内容定位**: 三类报告是"同一内容在不同时间维度的统计"，不是"差异化内容"

潘老师观点：
- **日报更关键**: 家长端次日留存率较高，日数据是家长更关心的实时学习情况

**决议**:
- 日报更关键
- 日报差异化内容：当日学习内容是日报特有且家长重点关注的部分
- 内容关联性：日报和阶段报应采用统一的学习效果评价标准
- 用户覆盖：三类报告并非用户分层内容，所有用户都有需求

### 🗓️ 2025-09-29 核心决策讨论

**背景**: 讨论日报与阶段报的分课时展示、学习行为动态展示、内容结构设计

**ui观点**:
- **分课时展示**: 不应分课时展示，避免页面冗余和提高认知成本
- **学习行为动态**: 应在阶段报中展示，更具分析价值
- **内容结构**: 统一评价标准，当日表现与阶段成长不分离

**决议**:
- **分课时展示**: 应该分课时展示，因不同课时教学目标不同
- **学习行为动态**: 包装为学习习惯，展示在阶段报告维度
- **内容结构**: 采用阅读能力分层体系（阅读理解能力、阅读积累、阅读习惯养成）

### 🗓️ 2025-10-11 UI 侧问题与方案讨论

**背景**: 产品提出原型设计，UI 针对原型提出问题
 **原型设计**: ![[D31480EF-B644-49E3-B147-71F2E998B8F3.png]]
**ui观点**:
- **阶段报展示时机与方式存在问题**
  - 叙事不连续：阶段报告是每日努力的结果，理应与日报有强因果关联。目前独立的Tab设计，让它们联系减弱，切断了"每日努力→阶段进步"的叙事顺序。
  - 无效交互：由于日报和阶段报的更新时间不同，阶段报数据是主题月结束后才会展示，在一个主题月的大部分时间里，点击"阶段"Tab，用户看到的都是空状态，对于用户来说是一个无效的，不满足用户期待，也造成了界面元素的冗余

- **信息结构冗余、错位**
  - "学习表现"与"能力提升"信息雷同：都使用学习技巧、阅读积累、阅读习惯三个维度的指标展示数据。从家长的视角来看，可能会难以快速区分这两个模块的差异和联系，增加了信息理解的成本。
  - 日报和阶段报中的"课程目标进度"展示逻辑错位：在默认的日报视图中，"课程目标进度"展示的是**全年维度**的数据，容易让用户产生理解偏差，误以为是今日数据。通常，家长对**近期、短期**的目标（单元目标）关注度更高频，而对长期目标（全年目标）的关注相对低频。当前设计将高频关注的信息放在了更深的操作路径里。

- **扩展性和兼容性**
  - 多课时情况下，页面信息繁杂，没有重点：每个课时都有学习表现和能力提升的数据，页面会变得很长，结构层级会变得复杂，可读性变差，家长需要费力地在大量同质化模块中滚动、寻找和对比。
  - 多个课包情况下，页面信息结构复杂：用户需要选课程 -> 选课包 -> 选报告类型(日/阶段)，这是一种层层下钻的结构，提高了交互成本，若同时遇到多课时情况，页面可用性极差。

Ui 方案：
 一、日报与阶段报的定位调整与展示逻辑

**定位**:
- 日报：当日学习内容与表现（局部细节）
- 阶段报：课程目标的整体达成情况（全局进度）

**关系**:
- 因果关联：每日学习积累推动阶段目标达成，当日数据变化直接反映在阶段报中
- 协同查看：用户需每日同步浏览两者，而非仅在主题月结束查看阶段报，实现 "局部细节 + 全局进度" 的联动感知

**方案**:
- 阶段报：数据每日更新（反映实时进度），总结仍保留主题月结束时更新（避免与日报重复）
- 页面整合：将日报与阶段报纳入同一页面流，构建 "今日学习→阶段成长" 的连贯叙事，体现课程系统性

二、学习总结优化方案（提升阅读效率与价值）

**现存问题**:
- 信息冗余：文字量大，重点不突出
- 内容重复："学习表现" 与 "学习重点" 存在重叠描述
- 价值不足：建议缺乏实际指导性，存在循环表述

**方案**:
- 迁移：将 "学习内容" 并入 "学习重点"，"学习建议" 移至二级半弹窗，仅保留 "学习问题" 作为入口钩子
- 强化：扩充 "学习建议" 的专业性与丰富度，定位为 "轻伴学课程"（如具体的蝙蝠图片、pdf 资料、儿歌推荐、互动游戏等）

三、多课包、多课时场景兼容方案

- 多课包：显示课包选择器
- 多课时：
  - 基础展示：显示课时选择器，避免页面过长
  - 阶段汇总：阶段报中对同类数据进行合并展示
  - 特殊处理：同步练等与正课目标差异较大的内容，采用独立卡片单独展示

**决议**:
无异议，在当前方案基础上，添加以下内容：
1、阶段成长添加单元完成进度信息、支持用户切换单元
2、今日学情支持切换日期


## 策略与需求分析

### 需求分析

通常，家长的核心诉求可以归纳为：

1.  **短期诉求（日常）：寻求"确定性"和"安心感"。**
    *   **核心问题**： "我的钱今天花得值吗？"、"我的孩子今天有没有偷懒？"、"他今天到底学了些什么？"
    *   **用户心智模型**： 这是一种"日常签收"或"打卡"的心智。家长需要一个快速、清晰、正向的反馈，来缓解他们为孩子教育投入金钱和时间后的日常焦虑。他们此刻要的不是深度分析，而是"今天一切正常，且小有收获"的 reassurance。

2.  **长期诉求（周期性）：寻求"有效性"和"成长感"。**
    *   **核心问题**： "这段时间的投入，到底有没有用？"、"我的孩子在能力上（而不仅仅是分数上）有进步吗？"、"相比其他孩子，或者相比他自己，他的成长轨迹是怎样的？"
    *   **用户心智模型**： 这是一种"投资回报分析"的心智。家长需要看到超越日常表现的、结构化的成长证据，来确认他们选择的这个产品是正确、有效的长期投资。这是决定他们是否续费的关键决策依据。

### 改版方向

#### 1. 构建"每日努力→阶段进步"的连贯叙事
日报，阶段报逻辑关系紧密，构建"每日努力→阶段进步"的连贯叙事，体现课程系统性。


#### 2. 减轻"认知负担"，避免信息冗余"
- 取消时间维度切换选项，采用扁平页面结构，降低家长操作与适应成本。
- 以今日学情为主，阶段学情为辅，每月发送主题月总结

#### 3. 增强家长与孩子互动
- 当孩子表现优异时，明确提示 "家长可送花花鼓励孩子"，为家长提供具体、可落地的互动方式。
- 当表现较差时，可以给出补救办法

#### 4. 优化界面风格
体现学习报告的"计划专业性"不强，避免童趣显得过于"好耍"。就像我们想要的是一个严厉且活泼的老师。




### 二、阅读能力分层体系

阅读课程能力可归纳为三大核心维度：

| 核心能力维度     | 二级能力维度 | 具体内容                     | 具体行为                                                          |
| ---------- | ------ | ------------------------ | ------------------------------------------------------------- |
| **阅读理解能力** | 提取信息   | 提取文字信息、提取图片信息            | 从文本/图片中提取出题目要求的词、句，能答对信息提取题                                   |
|            | 推论分析   | 词语理解、句子理解、基础判断、推理分析、比较分析 | 准确理解词句含义，能答对字词理解题                                             |
|            | 理解整合   | 篇章理解、结构分析、归纳概括           | 把握文章结构与主旨，能答对概括题                                              |
|            | 评价鉴赏   | 赏析手法、赏析语言、赏析表达、多维评价      | 识别并赏析表达手法与语言特色，能答对赏析题                                         |
|            | 探究表达   | 探究性阅读、口语表达、创新表达、书面表达     | 在阅读中思考并表达个人见解，能答出思辨表达类的题目                                     |
|            | 基础识记   | 拼音、词语、句段、积累运用            | 识记各类基础知识，并能正确运用，答对基础题                                         |
| **阅读积累**   | 精读积累量  | 无二级标签                    | 本单元阅读量达到 xx 篇/xx 字本学期阅读量达到 xx 篇/xx 字                         |
|            | 表达规范度  | 无二级标签                    | 本单元完整表达 xx 篇/xx 字读后感本学期累计完整表达 xx 篇/xx 字读后感                   |
|            | 阅读兴趣范围 | 无二级标签                    | 本单元拓展 xx 类文本阅读 xx 篇/xx 字本学期拓展 xx 类文本阅读 xx 篇/xx 字**（主题文本标签）** |
| **阅读习惯养成** | 坚持阅读   | 无二级标签                    | 本单元坚持阅读 xx 天/xx 小时本学期坚持阅读 xx 天/xx 小时                         |
|            | 开口表达   | 无二级标签                    | 本单元坚持自主表达 xx 天本学期坚持自主表达 xx 天                                 |

**数据展示策略**：
- **日报维度**：主要展示"对应标签行为表现"，通过答题正确率和积累量两类数据进行呈现
- **阶段维度**：主要展示"零级标签→一级标签→二级标签"所示的能力进度，基于日报数据汇总得出各能力维度的进步数值

## 最新方案

### 一、页面结构与内容组织

#### 1. 整体页面结构
- 优化页面风格，提高专业感，避免过于童趣的设计
- 取消今日与阶段的 tab，将信息放在同一页面流中，构建"今日学习→阶段成长"的连贯叙事
- 顶部设计台历卡片，展示今日日期、连续学习、累计学习参数、本周课程完成进度

#### 2. 今日学情模块
- **学习表现**：展示当日学习效果数据，如正确率等可以直接体现孩子当日学习好不好的量化指标
- **学习内容**：展示当日具体学习内容的积累量，如 XX 具体内容的积累量
- **学习总结**：由 AI 自动生成的当日学习情况总结，重点突出学习问题作为入口钩子
- **学习建议**：移至二级半弹窗，扩充专业性与丰富度，定位为"轻伴学课程"

#### 3. 阶段学情模块
- **能力成长**：以课程单元的时间维度展示，而非自然月或自然周
  - 核心能力维度：阅读理解能力、阅读积累、阅读习惯养成
  - 二级能力维度：如提取信息、推论分析、理解整合等（详见阅读能力分层体系）
  - 展示各能力维度的进步数值和达成情况
- **学习总结**：单元整体学习情况的 AI 总结，突出阶段成果和进步
