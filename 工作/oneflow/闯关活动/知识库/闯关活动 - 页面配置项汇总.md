# 闯关活动 - 页面配置项汇总

> 本文档从《配置篇：如何上线》中提取，汇总了闯关活动后台所有页面/组件的简介、配置项及配置项说明。

---

## 活动基本信息配置

**简介：** 创建闯关任务后，首先需要填写任务的基本信息，包括名称、时间、类型、布局等。

| 配置项    | 是否必填 | 说明                                                                                         |
| ------ | ---- | ------------------------------------------------------------------------------------------ |
| 闯关任务名称 | 必填   | 展示在C端，在闯关活动页会展示                                                                            |
| 开始时间   | 必填   | **班级闯关活动：** ① 激活后立即；② 内容序号：课程解锁到第x篇课时的几点。**品牌闯关活动：** ① 发布后立即；② 选择时间：选择绝对时间                 |
| 结束时间   | 必填   | **班级闯关活动：** ① 指定时长：指定活动时间长度；② 内容序号：课程解锁到第x篇课时的几点。**品牌闯关活动：** ① 指定时长：指定活动时间长度；② 选择时间：选择绝对时间 |
| 活动封面   | 非必填  | 按规范填写即可，不展示在C端                                                                             |
| 闯关任务类型 | 必填   | ① 串行关卡：关卡有解锁，完成上一关才能解锁下一关；② 并行关卡：关卡无解锁，可任意选择关卡完成；③ 按时解锁关卡：关卡按时间解锁，和上一关是否完成无关               |
| 布局样式   | 必填   | ① 竖版：活动页竖向展示；② 横版：活动页横向展示                                                                  |

## 二、活动页配置

**简介：** 根据需要，选择功能组件，拼接成活动页。活动页由多个组件组成，每个组件可独立配置。

### 2.2 闯关引导形象

**简介：** 用于关卡定位的引导形象。

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |

### 2.3 闯关开场引入

**简介：** 用于活动进入时的开场引入，支持视频和动画两种方式。

### 2.4 通关完成动画

**简介：** 活动页的全局设置，控制导航栏样式。

| --- | --- | --- |

**简介：** 在活动页中展示图片，支持下载和链接跳转功能。

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |

| 模块背景 | 非必填 | 用于模块的背景图 |

### 2.8 关卡组件

**简介：** 闯关活动的核心组件，配置关卡的样式、类型、跳转地址、结算方式等。

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |
| 关卡组背景图 | 必填 | 上传背景图图片 |
| 关卡尺寸&位置 | 必填 | 默认是固定关卡位置和大小；自定义可以设置关卡的位置和大小 |

**关卡配置详情：**

| 配置项 | 说明 |
| --- | --- |
| **关卡样式** | |
| 未解锁 | 未解锁时的样式 |
| 已解锁 | 解锁但未完成的样式 |
| 已完成 | 解锁并已完成的样式 |
| **使用场景** | 用的很少 |
| 固定关卡 | 默认方式 |
| 可变关卡 | 配置期分群，用于某个关卡只对部分人群展示 |
| **关卡类型** | |
| 题目 | 游戏题 |
| 活动 | 拍摄活动/朗读活动/配音活动/话题活动/PK活动 |
| 视频 | 观看视频 |
| 完读 | 正补学课时 |
| 普通 | 跳转自定义的链接 |
| 环节 | 视频+答题 |
| **关卡跳转地址** | 根据类型，选择对应类型的内容地址，需前置准备好"相关资源配置"：① 题目：参考《题目关卡-配置说明》；② 活动：参考《活动关卡-配置说明》；③ 视频：参考《视频关卡-配置说明》；④ 完读：参考《完读关卡-配置说明》；⑤ 普通：参考《普通关卡-配置说明》；⑥ 环节：参考《环节关卡-配置说明》 |
| **关卡完成结算** | 默认展示，也可以自定义样式，也可以不展示 |
| **获得卡片** | 用于完成关卡"集卡"的玩法 |

**卡片管理配置：**

| 配置项 | 说明 |
| --- | --- |
| 卡片名称 | 卡片的标识名称 |
| 未获得样式 | 图片形式 |
| 已获得样式 - 放大前 | 图片形式 |
| 已获得样式 - 放大后 | 支持三种形式：图片/动画/动画+图片 |

## 四、奖励配置

**简介：** 配置活动的奖励机制，包括排行榜和集卡奖励。

### 4.1 排行榜

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |
| 排行榜开关 | 非必填 | 开关打开后：C端会展示"关卡"排行榜，适合关卡比较多、进行闯关关卡完成数比拼的活动 |

### 4.2 集卡奖励

**简介：** 需活动有「集卡玩法」才能开启。集卡至一定数量，可以获得"抽奖"机会。

**添加规则 - 每条规则需填写：**

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |
| 集卡数量 | 必填 | 获得奖励的条件 |
| 获得奖励 | 必填 | 目前只支持"抽奖" |
| 关联ID | 必填 | 绑定抽奖活动id，抽奖活动请在"营销系统"配置 |
| 提示图片 | 非必填 | 用于告知用户获得了一次抽奖机会 |

**抽奖活动配置注意事项：**

1. 要勾选：支持系统调用给指定用户发放抽奖次数
2. 配置发放抽奖次数：每天默认发放、每天最多发放、活动期间每个用户最多可发放
   - 要考虑用户能获得的最大次数，不能设置过小，导致发放失败

## 五、自定义配置

**简介：** 配置活动的自定义分享和广告。

### 5.1 自定义分享

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |
| 分享图 | 非必填 | 活动分享至微信的角标图片 |
| 分享主标题 | 非必填 | 活动分享至微信的主标题文案 |
| 分享副标题 | 非必填 | 活动分享至微信的副标题文案 |

### 5.2 自定义广告

**简介：** 在活动页中添加自定义广告位，每条广告需配置以下信息。

| 配置项 | 说明 |
| --- | --- |
| **广告位** | ① 右下角悬浮窗；② 优秀作品banner广告 |
| **关联类型 - 广告位key** | 当1个广告位需要给不同用户展示不同素材时使用。各广告位key值：右下角悬浮窗=51，优秀作品banner广告=57 |
| **关联类型 - 广告素材id** | 当1个广告位所有用户都展示1个素材时使用 |
