
## 玩法简介

**玩法：完成多个任务关卡挑战。** 支持6种关卡类型：

| 关卡类型 | 说明 |
| --- | --- |
| 题目 | 做游戏题（课内40+种题型） |
| 视频 | 看视频 |
| 环节 | 视频+答题（课内type21环节） |
| 活动 | 拍摄/话题/配音/朗读/PK |
| 完读 | 补学课程 |
| 普通 | 跳转任意链接（如抽奖） |

**活动关卡专属能力**（需包含”活动”类型关卡）：

*   **分享传播**：作品提交后可分享至微信、抖音、小红书等平台
    
*   **活动表彰**：活动结束后可评选奖项，奖励虚拟称号或实物
    *   人气奖：按微信点赞排名
    *   自定义奖：人工评选优秀作品
    *   参与奖：参与即获奖

#### 关卡组件

关卡组件是闯关活动的核心，用于配置关卡地图和每个关卡的行为。

**基础配置：**

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 关卡组背景图 | ✅ | 上传背景图 |
| 关卡尺寸&位置 | ✅ | 默认固定关卡位置和大小；选择"自定义"可手动设置每个关卡的位置和大小 |

**关卡配置：**

- **关卡样式**：分别配置三种状态的外观
    - `未解锁`：关卡未解锁时的样式
    - `已解锁`：已解锁但未完成的样式
    - `已完成`：已解锁并已完成的样式
- **使用场景**（较少使用）：
    - `固定关卡`：所有用户看到相同的关卡
    - `可变关卡`：配置期分群，某个关卡只对部分人群展示
- **关卡类型**：

| 类型  | 说明                | 资源配置文档                                                                                               |

| 题目  | 游戏题               | [题目资源配置](https://alidocs.dingtalk.com/i/nodes/7NkDwLng8ZM0NzRPuz0jK03qJKMEvZBY?utm_scene=team_space) |

|     |                   |                                                                                                      |

- **关卡跳转地址**：根据关卡类型，选择对应类型的内容地址。需前置准备好"相关资源配置"（见上表链接）。
- **关卡完成结算**：默认展示，也可自定义样式或不展示。
- **获得卡片**：用于完成关卡后触发"集卡"玩法。

**卡片配置：**

在【卡片管理】菜单中点击"新建卡片"，编辑卡片信息：

| 字段 | 说明 |
| --- | --- |
| 卡片名称 | 卡片的名称 |
| 未获得样式 | 图片（用户未获得该卡片时展示） |
| 已获得样式 - 放大前 | 图片（已获得卡片的小图展示） |
| 已获得样式 - 放大后 | 图片 / 动画 / 动画+图片（点击卡片后放大展示） |
