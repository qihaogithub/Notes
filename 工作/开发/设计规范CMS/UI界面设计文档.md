# 设计规范管理系统 - UI界面设计文档

## 1. 页面总览

本系统包含以下核心页面：

| 页面名称 | 页面类型 | 访问权限 | 主要功能 |
|---------|---------|---------|---------|
| 登录页 | 公共页面 | 所有用户 | 用户登录认证 |
| 首页/工作台 | 主页面 | 所有用户 | 快速访问、最近访问、搜索 |
| 流程列表页 | 列表页 | 所有用户 | 浏览和管理所有流程 |
| 流程详情页 | 详情页 | 所有用户 | 查看流程信息、页面列表 |
| 页面详情页 | 详情页 | 所有用户 | 查看页面信息、资源标注 |
| 资源详情页 | 详情页 | 所有用户 | 查看资源详细信息 |
| 流程编辑页 | 编辑页 | 编辑者、管理员 | 创建/编辑流程 |
| 页面编辑页 | 编辑页 | 编辑者、管理员 | 创建/编辑页面、资源标注 |
| 资源编辑页 | 编辑页 | 编辑者、管理员 | 创建/编辑资源 |
| 搜索结果页 | 结果页 | 所有用户 | 显示搜索结果 |
| 版本历史页 | 历史页 | 所有用户 | 查看版本历史、对比、恢复 |
| 资源库页 | 列表页 | 所有用户 | 浏览和管理资源库 |
| 用户管理页 | 管理页 | 管理员 | 管理系统用户 |
| 系统设置页 | 设置页 | 管理员 | 系统配置管理 |

---

## 2. 通用布局结构

### 2.1 主布局框架

所有登录后的页面采用统一的布局结构：

```
┌─────────────────────────────────────────────────────────────┐
│  顶部导航栏 (Header)                                          │
│  Logo | 面包屑导航 | 搜索框 | 用户菜单                         │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                   │
│  侧边栏   │            主内容区域 (Main Content)             │
│ (Sidebar) │                                                   │
│          │                                                   │
│  - 导航   │                                                   │
│  - 树形   │                                                   │
│  - 收藏   │                                                   │
│          │                                                   │
└──────────┴──────────────────────────────────────────────────┘
```

### 2.2 顶部导航栏 (Header)

**高度**: 56px

**布局结构**:
```
[Logo] [面包屑导航] [搜索框] [通知图标] [用户头像/菜单]
```

**组件说明**:
- **Logo**: 系统标识，点击返回首页
- **面包屑导航**: 显示当前层级路径，如 "首页 > 登录流程 > 登录页"
- **搜索框**: 全局搜索入口，支持搜索流程、页面、资源
- **通知图标**: 显示评论通知、协作通知等
- **用户头像/菜单**: 显示用户信息，点击展开下拉菜单（个人中心、设置、退出）

### 2.3 侧边栏 (Sidebar)

**宽度**: 240px（可折叠至64px）

**布局结构**:
```
┌─────────────────┐
│ 导航菜单         │
│ ├─ 首页         │
│ ├─ 流程列表     │
│ ├─ 资源库       │
│ └─ 设置         │
├─────────────────┤
│ 快速访问         │
│ ├─ 最近访问     │
│ └─ 收藏夹       │
├─────────────────┤
│ 树形导航         │
│ ├─ 流程A        │
│ │  └─ 页面1     │
│ └─ 流程B        │
└─────────────────┘
```

**组件说明**:
- **导航菜单**: 主要功能入口
- **快速访问**: 最近访问的内容和收藏的内容
- **树形导航**: 显示流程-页面-资源的层级结构

**组件说明**:
