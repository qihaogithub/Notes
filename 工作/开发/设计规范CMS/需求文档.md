# 设计规范管理系统 - 产品需求文档

## 0. 需求痛点分析

当前设计规范使用在线文档编辑，存在以下核心痛点：

### 0.1 编辑层面：功能受限

在线文档编辑器难以实现高级标注功能，无法满足复杂场景需求：
- 缺乏资源标注能力，无法在页面预览图中标注资源位置
- 无法实现分层标注，难以精确展示资源细节

### 0.2 阅读层面：理解困难

文档索引图与内容分离，阅读体验不佳：
- 索引图固定在文档顶部，滚动浏览时无法同步查看
- 资源与页面的关联关系不直观，理解成本高

### 0.3 自动化层面：数据缺失

缺乏结构化数据，导致自动化程度低：
- 无标准数据接口，开发需手动配置资源参数（尺寸、格式等）
- 资源规范修改后，系统无法自动同步更新
- 文档与实际配置平台数据不一致，易产生偏差

## 1. 项目概述

本系统是一个面向团队内部的设计规范管理平台，旨在提供高效的设计资源组织、版本管理和协作体验，支持设计规范的结构化管理与便捷访问。

### 系统目标使用场景

#### 场景一：UI设计师创建新的设计规范

**核心特点**：文档式编辑体验，流程非必需，页面为核心单元

- **创建页面**：上传页面预览图，以文档编辑形式添加页面描述
- **插入资源**：在页面中插入资源，支持从资源库选择复用或新建资源
- **资源描述**：为资源添加结构化描述（格式、尺寸等）和非结构化描述（制作要求等）
- **资源标注**：在页面预览图上标注资源位置（标点/边框/分层标注）
- **组织流程**：将多个页面组织成流程，支持复用现有页面或新建页面
- **发布版本**：发布时自动创建版本快照

#### 场景二：运营设计师/运营查阅设计规范

**核心特点**：多视图支持，多种访问方式

- **搜索访问**：通过全文搜索找到所需的流程、页面或资源
- **链接访问**：通过协作者分享的链接直接访问，链接可定位到流程/页面/资源
- **流程视图**：查看流程下的所有页面列表，快速浏览整个业务流程
- **页面视图**：查看单个页面及其包含的所有资源标注和描述
- **资源视图**：查看单个资源的详细信息，包括结构化参数和非结构化说明


#### 场景三：资源复用与更新

**核心特点**：引用机制，一处更新全局生效

- **页面中复用资源**：新建页面时，新建资源或从资源库选择现有资源引用
- **流程中复用页面**：编辑流程时，新建页面或从页面库选择现有页面引用
- **资源更新**：修改资源/页面后，所有引用自动显示最新版本
- **引用追踪**：查看资源被哪些页面引用，避免误删
- **依赖管理**：删除资源或页面时，系统提示引用关系

#### 场景四：开发调用
- **调用接口**：通过数据接口获取资源的结构化参数（尺寸、格式、描述等）

## 2. 用户角色与权限

### 2.1 角色定义


| 角色                    | 描述                   | 核心权限                          |
| :------------------------ | :----------------------- | :---------------------------------- |
| **管理员**              | 系统最高权限管理者     | 用户管理、系统配置、所有内容管理  |
| **编辑者**（设计师）    | 设计规范的创建与维护者 | 创建/编辑规范、上传资源、发布内容 |
| **阅读者**（开发/其他） | 规范的使用者与查阅者   | 查看规范、下载资源、调用数据接口  |

### 2.2 权限需求

- **身份认证**：系统需提供用户登录与身份验证机制
- **访问控制**：不同角色对内容的访问权限需严格区分
- **操作审计**：关键操作需记录操作者信息

## 3. 系统层级结构

### 3.1 三级结构定义

系统采用**流程 → 页面 → 资源**的三级层级结构：

```
流程 (Flow)
  └── 页面 (Page)
        └── 资源 (Resource)
```

#### 3.1.1 流程 (Flow)

**定义**：流程是最高层级的内容组织单元，代表一个完整的业务流程或设计主题。

**特性**：

- 一个流程可包含多个页面
- 流程之间相互独立，无层级嵌套关系
- 流程需包含基础信息：名称、描述、封面图、创建者、创建时间

#### 3.1.2 页面 (Page)

**定义**：页面是流程下的具体设计单元，代表某个界面或设计场景。

**特性**：

- 一个页面可包含多个资源
- 页面必须包含预览图（强制要求）
- 页面预览图需标注所有引用的资源位置
- 页面可被多个流程引用（复用机制）
- 页面需包含基础信息：名称、描述、预览图、创建者、创建时间

#### 3.1.3 资源 (Resource)

**定义**：资源是最小的设计资产单元，代表可复用的设计元素。

**特性**：

- 资源可包含预览图（非强制要求）
- 资源可被多个页面引用（复用机制）
- 资源需包含基础信息：名称、类型、描述、预览图（可选）、创建者、创建时间

### 3.2 结构关系说明


| 关系类型         | 说明   | 业务场景                                       |
| :----------------- | :------- | :----------------------------------------------- |
| **流程 → 页面** | 一对多 | 一个登录流程包含登录页、注册页、忘记密码页     |
| **页面 → 资源** | 一对多 | 一个登录页包含按钮组件、输入框组件、Logo图标   |
| **资源 → 页面** | 多对多 | 一个按钮组件可被登录页、注册页、个人中心页引用 |
| **页面 → 流程** | 多对多 | 一个页面设计可被多个业务流程复用               |

## 4. 资源管理需求

### 4.1 资源类型

系统需支持以下资源类型：


| 资源类型     | 描述                                 |
| :------------- | :------------------------------------- |
| **图片资源** | PNG、JPG、SVG、WebP                  |
| 动效资源     | GIF、SVGA、Spine、Unity 动效包、Rive |
| **视频资源** | MP4等视频文件                        |
| **音频资源** | 音效、背景音乐等音频文件             |
| **色值资源** | 颜色色值                             |
| **文字资源** | 页面中的可配置文字                   |

### 4.2 资源复用机制

- **引用机制**：页面通过引用方式使用资源，而非复制
- **一处更新，全局生效**：资源更新后，所有引用该资源的页面自动显示最新版本
- **引用关系追踪**：系统需提供资源引用关系的查询功能，可查看某个资源被哪些页面引用
- **资源依赖管理**：删除资源时需提示该资源被哪些页面引用，避免误删

### 5. 页面展示需求

### 5.1 页面预览图要求

- **强制要求**：每个页面必须包含预览图
- **预览图内容**：预览图应完整展示该页面的设计效果
- **资源位置标注**：预览图上需标注所有引用的资源位置

### 5.2 资源标注方式

系统提供三类资源标注方式，适用于不同的业务场景和资源类型。


| 标注类型         | 适用场景                   | 实现方式                                 | 视觉表现               |
| :----------------- | :--------------------------- | :----------------------------------------- | :----------------------- |
| **标点标注**     | 所有资源类型的基础标注     | 在页面预览图中添加数字圆圈形式的标点标记 | 显示数字编号的圆形标记 |
| **高亮边框标注** | 图片、图标、组件等可见资源 | 在页面预览图中绘制高亮显示的边框         | 在资源周围显示高亮边框 |
| **高级分层标注** | 需要精确展示资源的场景     | 将引用资源的预览图叠加显示到页面预览图中 | 资源预览图叠加显示     |

#### 5.2.0 通用交互与高亮规则

所有标注方式均遵循以下通用交互规则和高亮效果。

**通用编辑操作**：

- 支持标注的拖拽移动
- 支持标注的删除
- 标注样式可配置（预置几种）

**通用交互需求**：

- 支持点击资源，自动高亮该资源的标注（标点、边框、高级）
- 支持鼠标悬停时临时高亮资源标注

#### 5.2.1 标点标注

**功能描述**：使用数字圆圈形式的标点进行资源位置标注。

**特有功能**：

- 在页面预览图中提供添加标点的绘图功能
- 标点以数字圆圈形式显示（如①、②、③）
- 标点编号自动生成，支持手动调整顺序

**适用场景**：

- 所有资源类型的基础标注
- 快速标注多个资源位置
- 资源位置无需精确边界的场景

#### 5.2.2 高亮边框标注

**功能描述**：使用高亮显示的边框进行资源位置标注。

**特有功能**：

- 在页面预览图中提供绘制圆角矩形边框的绘图功能
- 支持边框的调整大小
- 支持边框的圆角设置

**适用场景**：

- 图片、图标、组件等可见资源的精确标注
- 需要明确资源边界的场景
- 资源形状规则的场景

#### 5.2.3 高级分层标注

**功能描述**：将引用资源的预览图叠加显示到页面预览图中，形成高亮效果，支持分层展示和丰富的交互功能。

**核心原理**：

- 依赖引用资源的预览图配置，支持拖动和缩放，用户调整资源预览图叠加到页面预览图中合适位置和大小
- 通过分层展示实现资源的精确查看和对比

**分层规则**：

- **基础层**：页面预览图、标点和边框标注
- **资源层**：所有引用的资源元素（高级分层标注的核心层）

**适用场景**：

- 需要精确展示资源细节的场景
- 需要对比资源在不同页面中使用效果的场景
- 需要查看资源独立效果的场景
- 复杂页面包含多个资源时，通过分层展示便于查看单个资源
- 需要查看动效资源的完整动画效果时

### 5.5 不同资源类型的标注支持

不同资源类型对三类标注方式的支持程度不同，系统需根据资源类型提供相应的标注功能。


| 资源类型     | 标点标注 | 高亮边框标注 | 高级分层标注 | 说明                                   |
| :------------- | :--------- | :------------- | :------------- | :--------------------------------------- |
| **图片资源** | 必需支持 | 必需支持     | 必需支持     | 可见资源，需完整支持所有标注方式       |
| **动效资源** | 必需支持 | 必需支持     | 必需支持     | 可见资源，需完整支持所有标注方式       |
| **视频资源** | 必需支持 | 必需支持     | 必需支持     | 可见资源，需完整支持所有标注方式       |
| **音频资源** | 必需支持 | 可选支持     | 不支持       | 音频资源在页面中不可见，仅标点标注即可 |
| **文字资源** | 必需支持 | 可选支持     | 不支持       | 简单文字资源无需高级标注方式           |
| **色值资源** | 必需支持 | 可选支持     | 不支持       | 色值资源标点标注位置即可               |


## 6. 编辑与协作需求

### 6.1 编辑体验

- **所见即所得**：编辑态与预览态高度一致，消除编辑与查看的割裂感
- **快速插入**：支持快捷方式快速插入标题、列表、图片、资源等元素
- **拖拽排版**：支持内容块的拖拽排序
- **实时保存**：编辑内容实时自动保存，避免数据丢失

### 6.2 资源插入

- **拖拽上传**：支持将文件直接拖入编辑器，自动创建资源并插入
- **资源引用**：支持从资源库中选择已有资源插入到页面中
- **资源预览**：插入资源前可预览资源内容
- **批量插入**：支持一次插入多个资源

### 6.3 版本管理

- **手动创建版本**：用户可手动创建版本快照
- **发布版本**：发布时自动创建版本快照
- **版本历史**：提供版本历史列表，显示版本名称、创建时间、创建者
- **版本对比**：支持查看不同版本之间的差异
- **版本恢复**：支持将文档恢复到历史版本

### 6.4 协作机制
- **评论功能**：在流程、页面、资源上添加评论
- **协作编辑**：多人同时编辑时的冲突处理机制

## 7. 搜索与导航需求

### 7.1 全文搜索

- **搜索范围**：支持搜索流程、页面、资源的名称和描述
- **模糊匹配**：支持关键词模糊匹配
- **搜索结果**：显示匹配的流程、页面、资源列表
- **快速跳转**：点击搜索结果可直接跳转到对应内容

### 7.2 资源检索

- **按类型筛选**：支持按资源类型筛选（图片、视频、色值等）
- **按流程筛选**：支持按所属流程筛选资源
- **按页面筛选**：支持按所属页面筛选资源
- **引用关系查询**：查询某个资源被哪些页面引用
- **反向查询**：查询某个页面引用了哪些资源

### 7.3 导航体验

- **面包屑导航**：显示当前内容的层级路径（流程 > 页面 > 资源）
- **侧边栏导航**：提供流程、页面、资源的树形导航
- **快速跳转**：支持在流程、页面、资源之间快速跳转
- **收藏功能**：支持收藏常用的流程、页面、资源

## 8. 数据输出需求

### 8.1 规范数据导出

- **完整导出**：支持导出流程的完整规范数据
- **按需导出**：支持导出单个页面或单个资源的数据
- **格式支持**：支持导出为JSON、XML等结构化格式
- **版本导出**：支持导出指定版本的数据

### 8.2 数据接口

- **规范读取接口**：提供读取流程、页面、资源数据的接口
- **接口鉴权**：接口访问需进行身份验证和权限控制
- **接口文档**：提供完整的接口文档和使用说明
