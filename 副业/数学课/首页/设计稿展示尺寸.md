# 多端适配标准规范 

**核心口诀：“底图铺满屏，内容锁中心，UI 贴边缘”**
本规范旨在建立“一次设计，多端自动适配”的标准流程，彻底解决横屏应用在手机、平板等不同比例设备上的适配问题，确保 100% 的设计还原度。

---

## 📐 一、 核心尺寸与画板定义

全局仅使用唯一尺寸进行设计，告别针对不同机型出图的繁琐流程。

| 区域名称 | 尺寸 $(宽 \times 高)$ | 核心作用与边界 |
| :--- | :--- | :--- |
| **🖼️ 基准设计画布** | ** $1920 \times 1080$ ** | **唯一的画板尺寸。** 包容最长比例的全面屏，全屏背景图必须铺满此尺寸。 |
| **🛡️ 核心安全区** | ** $1360 \times 730$ ** | **绝对安全不被裁切的区域。** 屏幕正中心位置，所有教学互动内容必须限制在此框内。 |
| 📱 手机极限参考 | $1756 \times 810$ | 常见修长型手机尺寸边界参考（约 19.5:9）。 |
| 💻 Pad 极限参考 | $1440 \times 1080$ | 常见平板电脑尺寸边界参考（约 4:3）。 |

---

## 🍰 二、 三层视图结构与适配规则（核心逻辑）

画面上的所有元素必须被严格归类为以下“三层”，每一层的适配逻辑完全不同：

### 1. 底层：背景层 (Background Layer)
*   **元素类型：** 纯背景图、无信息量的场景底纹。
*   **适配规则：【等比缩放，铺满全屏】**
    背景图始终保持比例，短边撑满屏幕，长边超出屏幕的部分自动裁剪。保证在任何设备下不留黑边、不变形。

### 2. 中层：核心内容层 (Main Content Layer)
*   **元素类型：** 字母动画、描红虚线、教学插画、核心互动操作区。
*   **适配规则：【中心锚点定位 (固定安全区居中)】**
    内容层**不感知物理屏幕边缘**！将 $1360 \times 730$ 视为一个固定大小的“刚性盒子”，这个盒子永远死死钉在物理屏幕的正中央。盒内的所有元素，仅相对于这个 $1360 \times 730$ 的中心点保持相对距离。

### 3. 顶层：UI 控件层 (UI / HUD Layer)
*   **元素类型：** 关闭按钮(X)、进度条(22/42)、功能图标等。
*   **适配规则：【边缘锚点吸附】**
    UI 控件不待在安全区内，而是根据真实设备的屏幕边缘进行“锚点吸附”（如：关闭按钮永远距离屏幕左上角 $X$ 像素），并自动避开刘海屏区域。

---

## 🎨 三、 UI 设计师操作规范

1.  **统一画板：** 所有的页面排版，**只画 $1920 \times 1080$ 一种尺寸**。
2.  **设置参考线：** 在画板中拉出 $1360 \times 730$ 的居中参考线（或制作全局半透明蒙版）。
3.  **克制排版：**
    *   关键画面、动画主体**绝不允许**越过 $1360 \times 730$ 的参考线。
    *   背景必须画满整个 $1920 \times 1080$ 画板。
4.  **切图交付：**
    *   全景背景图：导出完整 $1920 \times 1080$。
    *   UI 控件：贴边 UI 单独切图（如 48 x 48 icon），**切忌**带上全透明的全屏背景导出。
    *   标注：在蓝湖/Figma 中，需文字备注 UI 控件的吸附规则（如：“吸左上角，距离左 40/上 40”）。

## ⚛️ 四、 React Native 研发实现指南

开发仅需利用一套设计素材，无需写大量的 JS 动态计算代码，依靠 Flexbox 和容器特性即可完成自动适配。

**1. 背景层开发：**
使用 `Image` 或 `ImageBackground`，设置 `resizeMode="cover"`，将其铺满全屏（绝对定位或 flex:1）。

**2. 核心内容层开发（安全区居中法则）：**
**切勿**使用屏幕宽度去动态计算边距。直接创建一个固定尺寸为 `1360 x 730` 的容器，利用外层 Flex 居中。
```jsx
// RN 核心代码结构参考
import React from 'react';
import { View, StyleSheet } from 'react-native';

const ContentLayer = () => {
  return (
    // 1. 最外层：铺满全屏，负责将内层盒子绝对居中
    <View style={styles.fullscreenWrapper}>
      
      // 2. 核心安全区容器：尺寸写死，不随屏幕尺寸拉伸缩放
      <View style={styles.safeAreaContainer}>
        
        {/* 3. 实际业务内容（字母 B 等）：在此盒子内使用绝对定位即可，原点为安全区中心 */}
        <View style={styles.letterB} />
        
      </View>
    </View>
  );
};

const styles = StyleSheet.create({
  fullscreenWrapper: {
    flex: 1, 
    justifyContent: 'center', // 垂直居中
    alignItems: 'center',     // 水平居中
  },
  safeAreaContainer: {
    width: 1360,   // 严格对应设计稿的核心安全区宽度
    height: 730,   // 严格对应设计稿的核心安全区高度
  },
  letterB: {
     position: 'absolute',
     // ... 具体坐标
  }
});
```

**3. UI 控件层开发：**
使用绝对定位 (`position: 'absolute'`)。结合 RN 的 `SafeAreaView` 或 `react-native-safe-area-context` 获取安全边距，将关闭按钮等吸附在 `top, left, right` 边缘，确保不被手机摄像头或圆角遮挡。
