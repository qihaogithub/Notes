一个练习环节结束的结果反馈 UI 界面设计，页面分为左、右、底三部分：
1. 左侧：显示文字 “环节完成”、“正确率”，评级标识 SS。
2. 右侧统计卡片：上方标注正确 30、错误 8；下方是题号方格，粉色格子为错题（共 8 题），绿色格子为做对的题目。
3. 底部三个按钮，从左到右依次是：重新练习、错题练习、完成。
4. 背景：简约干净，避免真实场景，扁平设计
风格：适合于儿童教育产品，Q 版科技风，平涂为主，轻微体积感。圆具有未来科技与自然生态融合的轻卡通游戏感。
配色：清新明亮、以蓝色为主色、绿色为辅助色。
结构：圆润柔和
负面约束：避免纯写实材质、复杂纹理、强烈光影、尖锐造型、过度密集的装饰以及灰暗沉重的配色。


    


- 采用非常柔和的浅蓝色到白色的双色渐变作为大背景，仅可点缀极淡的、半透明的科技感抽象环形线条或微弱的散景点缀，以确保视觉焦点完全集中在 UI 面板和按钮上。

**3. 风格与配色：**

- 适合儿童的 Q 版轻科技风格，造型圆润温和，无尖锐边缘。
- 采用轻微的玻璃拟态（Glassmorphism）和弱立体感，平涂为主，轻微体积。
- 配色清新明亮，以科技蓝、自然绿为主色调，点缀粉色与橙色，整体明快且具有亲和力。

**负面约束：** 避免任何复杂的 3 D 写实场景、复杂的背景纹理、刺眼的光影、尖锐的造型以及灰暗沉重的配色。不要在背景中绘制自然风光和草地。
