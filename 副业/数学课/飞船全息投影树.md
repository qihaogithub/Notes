这是一款专为儿童设计的数学教育 App 手机端横屏 UI 界面。该界面承担着“知识图谱”的核心功能，通过**全息能量树**的视觉形式，系统化地展示小学 1-6 年级数学知识架构。界面直观地呈现了用户在不同知识维度的掌握程度（未解锁、学习中、已掌握），通过游戏化的宇宙探索情境，将枯燥的知识体系转化为一场动态的、可交互的星际远征。

### 概念主题：探索宇宙的“全息数字之树”

**1. 整体氛围与构图**
*   **视角**：“太空舱驾驶台”第一人称视角。玩家仿佛坐在飞船驾驶舱内，透过巨大的透明舷窗看向宇宙。
*   **主体位置**：在舷窗外的宇宙正中央，悬浮着一棵巨大的、由纯粹的“光与数据”构成的**全息科技树**。
*   **色彩基调**：背景是深邃的宇宙蓝和紫蓝色星云。科技树的主体颜色为科技感的**青蓝色（Cyan）**，代表已经掌握或正在学习的节点则散发着温暖且引人注目的**荧光绿**或**全息金。

**2. 核心视觉：科幻树的造型**
*   **树干（主根基）**：不再是木头树桩，而是一个巨大的**几何光柱**或由无数条发光**光纤光缆**汇聚而成的“能量通道”。树干的底部连接着太空舱的投影装置，仿佛这棵树是由飞船向外投射出的全息影像。树干内部隐约有数字（如 0, 1, 2, 3, π）和基础几何图形在像数据流一样自下而上流动（寓意数学的基础）。
*   **树枝（知识脉络）**：光纤树干向上生长并分叉。树枝不是生硬的直线，而是类似**电路板上的走线（发光的折线）**，或者**神经元网络连接线**，带有一定的弧度和分型结构。整体外轮廓依然保持一棵“参天大树”的繁茂形状。

**3. 知识节点（树上的果实/星辰）**
节点的设计要紧扣“掌握程度”，并结合数学元素：
*   **已掌握节点（如：数与代数）**：
    *   **外观**：饱满、明亮的**3 D 全息能量球**（类似图 3 发绿光的球体），外围带有自转的几何光环。
    *   **内部**：清晰显示数学符号（如 $X^2$，$\div$，几何体）。球体连接的树枝呈现高亮的脉冲光流，表示能量已满。
*   **学习中节点（如：图形位置）**：
    *   **外观**：半透明的蓝色能量球，内部有类似“进度条”的液体光效或环形加载线圈。
    *   **视觉**：保持呼吸灯般的闪烁状态，鼓励用户去完成它。
*   **未解锁节点（待探索领域）**：
    *   **外观**：去除了圆球实体，变成了一个由细线构成的**立体几何框架（如正八面体或多面体的线框）**。
    *   **视觉**：颜色为暗灰色或半透明的暗蓝色，中心悬浮着一个充满科技感的全息小锁图标（类似图 1/图 2 的锁，但要有 UI 透明感）。连接它的“树枝”是暗淡的虚线。

**4. 细节与背景**
*   **背景层**：深空背景中，可以加入极其微弱的“三维坐标系”网格（Grid）或星云组成的斐波那契螺旋线，暗喻数学是宇宙的底层逻辑。
*   **漂浮物**：在科技树周围，偶尔有极小的全息发光碎片（如三角尺、圆规、加减乘除符号）像星尘一样缓慢漂浮。

**5. 底部太空舱 UI 操作台（保留图 3 优点）**
*   保持图 3 底部的机械控制台设计，但可以增加一些联动感。
*   操作台正中央是这棵全息树的“发射源”。
*   数据面板上的“已掌握 12%”、“学习中 54%”可以用具有科幻感的 HUD（抬头显示器）仪表盘来呈现，配合动态跳动的数值。

### 总结画面给人的感受：
**这是一棵由星光和数据流孕育在宇宙深处的生命之树。它既有植物不断向上生长、开枝散叶的生命力（代表知识的积累和扩张），又有极强的未来科技感（代表探索未知）。学生不是在枯燥地做题，而是在驾驶飞船，点亮宇宙中的数学真理之树。**
