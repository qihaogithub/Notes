设计一个儿童横向关卡游戏 UI 界面。

俯视地图，类似保卫萝卜关卡地图，室内场景、2D 扁平化、Q 版轻科幻、具有未来科技与自然生态融合的轻卡通游戏感、一些绿色为主色

### 顶部导航栏
- 返回箭头按钮、年级标签「L 2 一年级」+ 刷新图标
- 右侧分类标签组：高亮蓝色「全部」，并列白底标签：图形与几何、统计与概率、数与代数、综合与实践

### 课程闯关主内容
波浪渐变轨道承载一排课程关卡：
- 轨道分两种：绿色（已解锁 / 学习中）、浅米色（锁定未开放）
- 关卡统一样式：圆形图标 + 课程分类标签 + 课程名，分三种状态：已完成（绿色对勾）、进行中（进度环）、锁定（锁 + 解锁日期）
- 当前选中关卡下方悬浮两个操作按钮：橙色「视频」、紫色「练习」

### 边角辅助元素
- 左下角功能按钮。
- 右下角：卡通教授人物 + 对话气泡引导文案

### 配色
- **空间基底**：以浅暖绿、奶油白为底色，占据墙面、地面、柱体和大部分建筑结构，奠定柔和明亮的绿色基调。
- **自然元素**：植物、藤蔓、花坛和生态装饰采用嫩黄绿、草绿色、中绿色，色彩鲜嫩通透，增强自然生机，但面积不夸张。
- **科技元素**：屏幕、灯带、全息装置、设备光边采用高明度亮青绿、荧光绿、薄荷绿，体现轻盈清爽的科技感，不做大面积铺满，仅局部强调。
- **点缀色**：少量橙黄色用于按钮、提示灯、局部发光细节和视觉焦点，与主绿色形成对比。
**整体氛围**：画面以绿色为主轴，暖绿基底 + 自然绿 + 科技亮绿，辅以橙黄点缀，呈现“科技绿洲”的视觉感受。
**避免**：避免整体偏冷蓝、避免蓝色大面积染满空间、避免黄绿色过重导致科技感不足、避免灰暗或脏色调。
