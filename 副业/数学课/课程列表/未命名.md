设计一个儿童数学 APP 横屏课程列表页面，采用“横版卷轴式半俯视关卡地图”形式展示。不要使用独立课程卡片，不要做成一个弯曲包围的室内大厅，也不要像在真实空间里拍摄的一张 2.5 D 照片。整体应更像一个真正的横版闯关游戏卷轴关卡地图（Side-scrolling Background），单层结构，左右连续延伸，看不到尽头，适合左右滑动浏览几十节课程。

页面顶部保留简洁 UI 导航区域，包括返回按钮、课包名称、课程分类筛选栏，以及用户信息入口。分类包括：全部课程、数与代数、图形与几何、统计与概率、综合与实践。顶部 UI 圆角、简洁、儿童友好，不喧宾夺主。

主体区域是一张“未来数学研究所”主题的横向课程地图。地图采用比普通 2.5 D 更高一点的半俯视视角，约 35° 到 50°，让整体更像游戏地图，而不是仿摄影角度的场景图。整个地图强调左右延展，不要弧形环绕结构，不要中央大厅式包围空间，不要前后纵深很强的房间感。场景应像横版卷轴游戏背景一样，结构平直、连续、自然向左右铺开。

课程节点沿一条清晰连续的横向路径排布，形成明确的闯关路线。路径可以是发光步道、浅色科技地轨、数学能量线路或生态研究路线，但整体应平直、连贯、明确服务于横向推进感。不要复杂弯曲路线，不要迷宫式结构。

每个课程不是独立大卡片，而是地图中的平面化关卡节点。节点采用统一、低矮、贴地、简化的结构，像平面化学习站、课程 tile、低台节点或地面课程面板。不要复杂机器装置，不要厚重建筑感，不要像一个个独立展台。每个节点包含：课程序号、课程名称、课程状态、课时封面。课时封面必须俯视平放，像贴在节点上的平面图片、小海报、小课程板，不要竖立屏幕，不要复杂外框。

未选中节点保持紧凑简洁，只显示课程序号、课程名称、课程状态和小尺寸平放封面。当前选中节点位于画面中央，适度放大，但仍然保持地图节点感，不要膨胀成独立大卡片。当前节点可局部展开显示“视频课”“课后作业”两个学习环节。左右两侧节点逐渐缩小或部分露出，明确传达可横向滑动查看更多课程。

课程状态包括：未解锁、已解锁、进行中、已完成。
- 未解锁：灰白低饱和，锁图标
- 已解锁：正常显示，轻提示
- 进行中：中央节点高亮，边缘发光，轻微放大
- 已完成：勾选标记，轻松积极

背景场景设定为“未来数学研究所室内卷轴地图”，但要弱化真实建筑空间感，不要出现大面积弯曲墙体、环绕式窗户、摄影式前景装置或室内展厅感。背景应更像横版游戏地图的连续场景底图：左右延伸的研究所步道、轻科技地面、少量绿植、少量研究装置、远处窗景或生态景观作为氛围点缀。背景只承担氛围和主题，不应干扰课程节点识别。

整体画面应更像“儿童数学闯关地图”而不是“室内空间照片”。要有明显的地图感、卷轴感、游戏关卡感、路径推进感。可以有轻度高差、平台层次和地面区块变化，但整体保持简单、平直、统一、可读。

### 风格
Q 版儿童科普插画风格，以扁平插画为基础，结合轻微 2.5 D 体积感。整体非写实、清新明亮、圆润规整，具有儿童游戏地图 UI 的感觉，偏游戏化、偏设计化，而不是偏摄影空间表现。

### 配色
- 空间基底：奶油暖白、浅暖灰
- 自然元素：嫩黄绿、草绿色、清新浅绿
- 科技元素：高明度天蓝、青蓝、浅湖蓝
- 点缀色：少量橙黄色用于当前节点、按钮、高亮提示

整体氛围阳光充足、通透明亮，以暖白和清新绿为主，辅以适量青蓝科技光效，形成“自然与科技并存”的未来数学学习地图。避免大面积冷蓝，避免背景过度复杂，避免颜色过脏或过灰。

### 结构
横版宽幅构图，半俯视视角，单层横向卷轴结构，强调左右连续延展。地图中心区域重点表现当前课程节点及其相邻节点，一屏展示约 5—7 个课程节点。整体不做封闭房间，不做弧形包围，不做照片式透视空间。

### 质感与光影
材质以半哑光塑料、软胶、喷涂金属和少量透明亚克力为主。表面平滑洁净，使用柔和渐变、轻阴影和适度高光表现轻微体积。采用明亮均匀的白昼漫射光，低对比、暗部明亮、整体轻盈柔和。

### 负面约束
避免独立课程卡片、避免弯曲大厅结构、避免封闭室内空间、避免像一张仿 2.5 D 摄影照片、避免环绕式窗景、避免过多建筑感、避免复杂立体装置、避免厚重科技机器、避免立起来的课程封面、避免复杂弯曲路径、避免多层空间、避免赛博朋克、避免暗黑科幻、避免过强写实感、避免杂乱装饰。
