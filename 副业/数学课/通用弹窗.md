设计一个**高品质轻科幻风 UI 弹窗**，用于儿童数学教育 / AI 学习类产品。

### 整体定位

风格为**轻科幻、未来科技、简洁高级、亲和**，带一点太空舱 / 智能设备控制面板的设计语言，但不要做成硬核机甲、赛博朋克或游戏 HUD。

整体需要像真实 APP 中可以落地使用的 UI 组件，而不是概念插画。

### 画面构图
- 16:9 横版画面
- 深灰色纯色背景，用于突出弹窗主体

- 弹窗水平垂直居中
    

### 弹窗主体

外轮廓不要使用普通圆角矩形，而是在圆润矩形基础上加入少量未来设备结构：
- 四角保持较大圆角
- 上下边缘中央加入轻微凹槽 / 梯形机械结构

整体轮廓应体现：

**圆润儿童产品感 + 精密科技设备感**

而不是尖锐、复杂的机甲装甲。


整体视觉感觉类似：

**未来学习终端 / AI 智能设备 / 太空舱控制面板的儿童友好版本。**

### 科技装饰

科技细节控制在整体面积的 10%以内。

### 内容区域
示例文字：

“弹窗文本最大三十个字，两行两行  
弹窗文本最大三十个字，两行两行…”

- 最多两行
    
- 深灰黑色文字
    
- 字体清晰、现代
    
- 行距舒适
    
- 不使用科技字体
    
- 不加入标题或图标
    
- 保持信息阅读优先
    

### 按钮区域

底部设置两个并排按钮，尺寸统一，间距约 20—30 px。

左侧为次按钮，右侧为主按钮

按钮不要做成立体游戏按钮，保持现代 APP UI 风格。



**70%现代教育 APP UI + 20%未来智能设备结构 + 10%科技灯光细节。**

整体比传统白色弹窗更有识别度，但仍然简洁、舒适、精致、易于实际产品落地。
