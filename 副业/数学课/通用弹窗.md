设计一个**高品质轻科幻风 UI 弹窗**，用于儿童数学教育 / AI 学习类产品。

### 整体定位

风格为**轻科幻、未来科技、简洁高级、亲和**，带一点太空舱 / 智能设备控制面板的设计语言，但不要做成硬核机甲、赛博朋克或游戏 HUD。

整体需要像真实 APP 中可以落地使用的 UI 组件，而不是概念插画。

### 画面构图

- 16:9 横版画面
    
- 深灰色纯色背景，用于突出弹窗主体
    
- 弹窗水平垂直居中
    
- 正面视角，无透视畸变
    
- 弹窗整体为横向圆角矩形，比例约 1.8:1
    
- 保持较大留白，整体干净、克制
    

### 弹窗主体

主体采用**白色 + 极浅冷灰色**，具有轻微立体层次。

外轮廓不要使用普通圆角矩形，而是在圆润矩形基础上加入少量未来设备结构：

- 四角保持较大圆角
    
- 上下边缘中央加入轻微凹槽 / 梯形机械结构
    
- 左右两侧局部向内收口
    
- 边缘可以有少量模块化切角
    
- 结构左右对称
    
- 不要加入过多零碎装饰
    

整体轮廓应体现：

**圆润儿童产品感 + 精密科技设备感**

而不是尖锐、复杂的机甲装甲。

### 材质表现

采用轻微的 2.5 D / 轻 3D UI 材质：

- 白色磨砂塑料
    
- 极浅灰金属结构
    
- 柔和高光
    
- 很轻的内阴影
    
- 极轻的悬浮投影
    
- 边缘具有细腻倒角
    

避免：

- 强烈金属反光
    
- 玻璃拟态
    
- 过度透明
    
- 重度发光
    
- 厚重游戏 UI
    

整体视觉感觉类似：

**未来学习终端 / AI 智能设备 / 太空舱控制面板的儿童友好版本。**

### 科技装饰

科技细节控制在整体面积的 10%以内。

可以在：

**顶部中央**  
加入 4—6 个短小蓝色状态灯 / 能量格。

**底部中央**  
加入对应的短线型设备指示灯。

**左右两侧**  
设计浅灰色嵌入式设备模块，每侧加入 2—3 个蓝色小型发光指示灯。

**内框**  
使用极细的浅蓝色线条，仅在四角局部出现，不要形成完整边框。

所有蓝色灯光只需微弱发光，不要出现强烈霓虹效果。

### 内容区域

弹窗内部保持大面积白色空间。

正文位于上半部分，左对齐或视觉居中排列。

示例文字：

“弹窗文本最大三十个字，两行两行  
弹窗文本最大三十个字，两行两行…”

- 最多两行
    
- 深灰黑色文字
    
- 字体清晰、现代
    
- 行距舒适
    
- 不使用科技字体
    
- 不加入标题或图标
    
- 保持信息阅读优先
    

### 按钮区域

底部设置两个并排按钮，尺寸统一，间距约 20—30 px。

左侧为**次按钮**：

- 白色背景
    
- 蓝色 2 px 左右描边
    
- 蓝色文字
    
- 大圆角矩形
    
- 不发光或仅有极轻阴影
    

文字：

**次按钮**

右侧为**主按钮**：

- 明亮科技蓝填充
    
- 白色文字
    
- 大圆角矩形
    
- 可以有轻微蓝色高光和柔和阴影
    
- 视觉权重明显高于次按钮
    

文字：

**主按钮**

按钮不要做成立体游戏按钮，保持现代 APP UI 风格。

### 配色

主色：

- 白色
    
- 极浅冷灰
    
- 中性深灰
    

科技强调色：

- 明亮科技蓝
    
- 少量浅青蓝
    

整体蓝色面积控制在 15%以内。

避免大面积紫色、绿色、红色以及多彩渐变。

### 视觉关键词

**轻科幻 UI、未来教育、AI 学习终端、儿童科技产品、白色智能设备、圆润机械结构、2.5 D UI、磨砂塑料、浅灰金属、蓝色状态灯、克制科技感、极简、高级、可落地 APP UI**

### 特别注意

不要：

- 赛博朋克
    
- 黑色机甲
    
- 复杂 HUD
    
- 六边形堆叠
    
- 大面积霓虹
    
- 满屏科技纹路
    
- 复杂机械零件
    
- 过多装饰线条
    
- 尖锐切角
    
- 儿童卡通插画
    
- 机器人或人物
    
- 游戏技能弹窗
    

最终效果需要体现：

**70%现代教育 APP UI + 20%未来智能设备结构 + 10%科技灯光细节。**

整体比传统白色弹窗更有识别度，但仍然简洁、舒适、精致、易于实际产品落地。
