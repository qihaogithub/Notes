## 三级细分圆球（24 个圆球）


#### （1）数的认识（4 个圆球）

- 整数的认识
    
    （树叶：自然数、0 的意义、数位与计数单位、大数的读写、因数与倍数、质数与合数）
- 小数的认识
    
    （树叶：小数的意义、读写、性质、大小比较、近似数）
- 分数的认识
    
    （树叶：分数的意义、读写、基本性质、约分与通分、真分数 / 假分数 / 带分数）
- 百分数与负数
    
    （树叶：百分数的意义、百分数与分数 / 小数互化、负数的意义与应用）

#### （2）数的运算（4 个圆球）

- 整数四则运算
    
    （树叶：加减乘除的意义、计算法则、运算顺序、运算律、简便运算）
- 小数四则运算
    
    （树叶：小数加减、小数乘除、混合运算、简便运算）
- 分数四则运算
    
    （树叶：分数加减、分数乘除、分数与小数混合运算）
- 运算应用与估算
    
    （树叶：估算策略、和差倍问题、归一归总问题、运算定律拓展）

#### （3）式与方程（3 个圆球）

- 用字母表示数
    
    （树叶：表示数量关系、运算定律、计算公式、含字母式子的化简）
- 简易方程
    
    （树叶：方程的定义、等式的性质、解方程、检验）
- 列方程解应用题
    
    （树叶：找等量关系、列方程、解常见应用题类型）

#### （4）比与比例（3 个圆球）

- 比的认识与性质
    
    （树叶：比的意义、读写、基本性质、化简比、求比值）
- 比例的认识与应用
    
    （树叶：比例的意义、基本性质、解比例、正反比例）
- 比例的实际应用
    
    （树叶：比例尺、按比例分配、正反比例应用题）

#### （5）常见的量（3 个圆球）

- 时间单位
    
    （树叶：时 / 分 / 秒、年 / 月 / 日、24 时计时法、平年闰年）
- 质量与长度单位
    
    （树叶：克 / 千克 / 吨、毫米 / 厘米 / 米 / 千米、单位换算）
- 面积与体积单位
    
    （树叶：平方厘米 / 平方分米 / 平方米、立方厘米 / 立方分米 / 立方米、容积单位）

### 2. 图形与几何模块（13 个圆球）

#### （1）图形的认识（4 个圆球）

- 线与角
    
    （树叶：直线 / 射线 / 线段、垂直与平行、角的分类、量角与画角）
- 平面图形
    
    （树叶：三角形、四边形、圆、扇形的特征与分类）
- 立体图形
    
    （树叶：长方体、正方体、圆柱、圆锥的特征）
- 图形的分类与关系
    
    （树叶：平面 / 立体图形的区分、特殊四边形的关系）

#### （2）图形的测量（4 个圆球）

- 周长计算
    
    （树叶：长方形 / 正方形周长、圆的周长）
- 面积计算
    
    （树叶：长方形 / 正方形面积、三角形 / 平行四边形 / 梯形面积、圆的面积）
- 表面积计算
    
    （树叶：长方体 / 正方体表面积、圆柱的侧面积与表面积）
- 体积与容积计算
    
    （树叶：长方体 / 正方体体积、圆柱 / 圆锥体积、容积的计算与换算）

#### （3）图形的运动（3 个圆球）

- 平移与旋转
    
    （树叶：平移的特征、旋转的特征、画平移 / 旋转后的图形）
- 轴对称图形
    
    （树叶：轴对称的意义、对称轴的画法、补全轴对称图形）
- 图形的放大与缩小
    
    （树叶：按比例放大 / 缩小、在方格纸上画图）

#### （4）图形与位置（2 个圆球）

- 方向与位置
    
    （树叶：上下 / 前后 / 左右、东南西北、八个方向、路线图）
- 数对与位置
    
    （树叶：用数对表示位置、根据数对找位置）
