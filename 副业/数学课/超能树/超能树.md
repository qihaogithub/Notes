一个儿童数学教育产品的 UI界面，手机端横屏。

#### 风格设定
高饱和明亮配色的生态科幻风格，画面对标《原神》大世界，采用皮克斯式 3 D 动画渲染，质感轻盈柔和，可爱治愈且温馨。材质线条圆润柔和，搭配微哑光科技塑胶与通透玻璃，观感温润协调。

#### 背景
一个高科技植物培育室内部场景：

1.  **墙体与结构**：
    *   背景是一个**穹顶状的弧形空间**，墙面采用温润的乳白色微哑光科技复合材质，带有微微的弧度和圆润的转角。墙壁上嵌有几条发着**温和浅绿色微光的光导纤维线条**，让科技感自然融入。
2.  **顶部天窗与光影**：
    *   屋顶中央是圆形的透明全息天窗。巨大的树冠在天窗外隐约可见。
    *   温暖的白昼阳光穿过天窗与树叶，形成一束束**柔和的金色丁达尔光束（耶稣光）**投射在室内，地面和工作台上洒下点点温和的投影，营造治愈、温馨的氛围。
3.  **背景层次（远景与留白）**：
    *   背景中可以有一扇圆形的观景窗，隐约透出窗外漂浮的空中小岛和蓝天白云。
    *   *注意（UI 防干扰）*：为了保证图 1 右侧“知识原理”卡片文字的阅读清晰度，背景的右半部分（卡片后方区域）应做**轻微的景深虚化（Gaussian Blur）**，或者叠加一层极其柔和的白蓝色渐变半透明遮罩，使背景不干扰前景 UI 的呈现。




## 核心功能
能量站代表学习功能，培育站代表智慧树功能，它们分别位于画面左右两侧，大小高度相似，中间用一条能量管连接。

#### 能量站(代表学习功能)
一个科技感建筑-能量站，舱门是一个圆角的滑动气密门，舱门中央嵌有一个发着温暖黄光的**开始学习**按钮。
能量站的屋顶上，有一个**巨大的、半透明的蓝色偏光玻璃球体**（像一个圆润的科技星球或水晶球），作为能量收集核心。球体周围环绕着**2-3 圈粗壮、圆润、发着温暖黄光的“磁悬浮能量环”**（类似土星环的 Q 版设计）。

#### 培育站（代表智慧树功能）
一个科技感建筑-培育站。树冠从屋顶中央延伸出来，化为**一个巨大、蓬松、圆滚滚的绿色树冠，像一把天然的绿色巨伞罩在科技小屋的上方**。



### 次要功能
位于页面右上角三个图标，**圆润的、像果冻一样半透明的科技徽章底座**中
1.  **真题题库**：一本 Q 版、书脊圆润的蓝色科技电子书。
2.  **每日挑战**：一个亮黄色的、像玩具一样有塑料光泽的 Q 版奖杯。
3.  **设置**：一个转角圆滑、带有一点科技蓝光圈的灰色齿轮。
