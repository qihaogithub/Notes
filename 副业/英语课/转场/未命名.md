

## 1. 页面整体布局

- 背景：温暖儿童书桌场景，浅色木纹桌面，柔和阳光投影，桌面四周摆放少量文具和小玩具（彩笔、尺子、书本、剪刀、贴纸），中间留出大面积干净空间。
    
- 中心：一张**平铺正视角的纸质地图**，地图四角圆润，轻微折痕和纸张厚度感，像大富翁冒险地图。
    
- 地图上：**弯曲路线串联四个关卡节点**，路线呈自然弯曲，左下为起点，右上为终点。
    
- 地图风格：儿童绘本风，颜色柔和，线条简洁，轻量装饰（小草、小树、小旗、小星星），保持清晰干净。
    

## 2. 关卡节点设计（立体折纸风格）

- 每个关卡不是便签，也不是地图插画场景，而是**立体折纸风格图标**，像小型纸艺装置立在地图节点上。
    
- 每个折纸关卡带有轻微立体感、纸折叠层次感和阴影，与地图底图分层。
    
- 每个关卡下方附带中英双语标签：
    
    - 中文主标题：较大、圆润可爱
        
    - 英文副标题：较小，作为说明文字
        
- 关卡状态：
    
    - **已完成**：关卡图标或标签上有绿色打钩徽章
        
    - **当前关卡**：IP立体形象站在该节点旁边，稍微放大高亮，带柔和光晕或小星点
        
    - **未解锁**：关卡图标略微降低饱和度，带小锁图标
        

### 四个关卡内容与折纸图标示例

1. **跟我读 / Read After Me**
    
    - 折纸元素：麦克风、打开的小书页、小音符
        
    - 颜色：暖黄色/橙色
        
2. **综合练习 / Comprehensive Practice**
    
    - 折纸元素：字母卡片、拼图块、小练习卡
        
    - 颜色：浅绿色
        
3. **巩固做题 / Review Exercises**
    
    - 折纸元素：铅笔、勾选题板、小练习纸
        
    - 颜色：浅蓝色
        
4. **录制绘本 / Record Storybook**
    
    - 折纸元素：打开的绘本、麦克风、录音波纹、小星星
        
    - 颜色：浅紫/粉紫
        

## 3. IP形象设计

- 立体公仔风格，不属于地图平面，像小棋子或立体公仔站在地图节点上。
    
- 动作根据关卡内容变化：
    
    - 跟我读：手持麦克风，张嘴朗读，开心专注
        
    - 综合练习：手持卡片或拼图，做任务状态
        
    - 巩固做题：拿铅笔面对题板，思考状态
        
    - 录制绘本：抱绘本或对麦克风，表现成果完成感
        
- IP位置随进度变化，站在当前关卡节点旁边或前方，显示“正在进行”状态。
    

## 4. 路线与装饰

- 路线用圆点或虚线连接四个关卡节点，可配小箭头、小星星、小旗子，呈大富翁风格。
    
- 路线经过已完成关卡可稍微高亮。
    
- 地图上轻量装饰（小树、小草、云朵、星星），不抢关卡和IP焦点。
