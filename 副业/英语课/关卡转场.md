请基于我提供的背景图和 IP 参考图，绘制一张适用于儿童英语学习 APP 的关卡选择 UI 设计稿，画幅为 16:9。

设计目标：
页面只展示 4 个关卡，不需要标题栏、按钮栏、返回键、进度条或其他多余 UI 控件。整体要像一个完整的 UI 设计稿，适合儿童教育产品，风格温暖、治愈、可爱、精致，具有轻微立体感和绘本感。

核心要求：
1. 四个关卡横向排成一排，但不要整齐平铺，要错落摆放，形成自然的节奏感和空间层次。
2. 四个关卡分别为：
- 跟我读 / Read After Me
- 综合练习 / Comprehensive Practice
- 巩固做题 / Review Exercises
- 录制绘本 / Record Storybook
3. 每个关卡都要同时显示中文主标题和英文小标题，英文作为次级信息，字号更小。
4. 只有“当前关卡”显示 IP 形象，其余关卡不要显示 IP。
5. 已完成关卡和待开始关卡只保留简洁图标化设计，不要出现 IP，避免画面拥挤。
6. 页面需要清晰体现三种状态：
- 已完成：用对勾、星星徽章或完成标记体现
- 当前关卡：最突出，体积最大，显示 IP，具有精美的立体绘本/立体书舞台效果
- 待开始：更简洁、更轻量，可用小锁、浅色、低饱和度体现未开始状态
7. 当前关卡保留精美的立体书舞台效果，其他关卡采用更简洁的小卡片、小徽章、低多边形或轻扁平化样式，明显比当前关卡更小、更简洁。
8. 整体画面要减少拥挤感，留白充足，视觉重心明确，避免每个关卡都做成复杂小场景。
9. 各关卡之间可以用轻量的虚线、星点路径、书签丝带或柔和连接线串联，但路径不要太抢眼。
10. 保持儿童教育 APP 的审美：圆角、低饱和暖色、Q 版、柔和光影、轻立体感、治愈感、精致感。

构图建议：
- 当前关卡占据画面视觉中心偏左或偏中位置，最大、最丰富
- 其余 3 个关卡分散排布在左右两侧，错落排列，大小更小
- 关卡之间距离适中，保证呼吸感和留白

- 巩固做题：铅笔、清单、练习纸元素
- 录制绘本：绘本、录音麦克风、故事书元素
