## 一、风格总览

### 1.1 风格名称
**治愈系轻立体扁平风**

### 1.2 核心关键词
```
Q版扁平风、粗细均匀的轮廓描边、造型圆润、低饱和马卡龙配色、
以纯色平涂为主，辅以轻立体感、软质均匀光、治愈感
```

### 1.3 差异关键词

| 元素类型 | 风格特征 |
|---------|---------|
| 图标、IP、控件 | 粗细均匀的轮廓描边 |
| 背景图 | 无描边 |

### 1.4 通用风格描述（AIGC 通用前缀）

```
低龄友好、Q版扁平风，平涂为主，圆润柔和的造型，轻立体感。
整体以低饱和度马卡龙色系，色调清新明快，氛围温馨又舒适。
软质自然光，光线均匀且没有生硬阴影，强化了"柔和治愈"的感觉。
所有物体都采用圆润化处理，线条平滑无棱，造型偏向简化、可爱的卡通化设计。
```

## 二、IP 形象设计规范

### 2.1 形象主体
**卡通水豚（卡皮巴拉）**

### 2.2 风格规范
- **轮廓**：粗细均匀的轮廓描边，线条干净利落
- **画风**：扁平风，以纯色平涂为主
- **立体感**：轻立体感，干净清爽
- **色调**：暖调柔和，治愈感拉满

### 2.3 颜色规范

| 部位 | 颜色名称 | 色值 | 应用范围 |
|-----|---------|------|---------|
| 身体 | 暖焦糖棕 | `#e08b48` | 身体、耳朵外侧、四肢 |
| 肚皮 | 浅暖杏色 | `#F6BC7E` | 腹部圆形区域 |
| 五官深色 | 深棕褐色 | `#995a2d` | 鼻子、爪子、耳朵内侧 |
| 腮红 | 暖粉色 | `#F78A8A` | 脸颊红晕 |
| 口腔 | 深酒红 | `#9f291a` | 口腔内部 |
| 舌头 | 浅粉色 | `#f9897a` | 舌头 |

### 2.4 形象延展要求
IP 形象需覆盖多种表情和场景动作，包括但不限于：
- **基础表情**：开心、疑惑、惊讶、害羞、困倦
- **互动动作**：打招呼、鼓掌、阅读、沐浴、休息
- **场景化**：戴墨镜休闲、睡觉、吃东西、举爱心等

### 拟人字母角色
Q 版拟人字母角色，拥有大眼睛、小嘴巴、粉色腮红和开心微笑表情，体现友善、活泼、儿童化气质。

以【字母】为主体，保持字母结构完整清晰，具有极高辨识度，任何装饰不得遮挡字母关键特征。大写与小写保持统一世界观和设计语言，通过颜色和细节进行区分，避免过于相似。


3 D 软陶黏土风格，配色鲜艳活泼，造型圆润饱满。


字母两侧生长短小圆润的黏土手臂，双手自然下垂；底部连接两条长度一致的黏土腿，自然站立，不做夸张动作。所有字母统一穿着圆头儿童雨靴风格鞋子，保持统一造型和比例。

纯白背景，主体居中，全身完整展示，统一光照、统一材质、统一比例，确保整个字母系列风格一致。

## 四、应用场景与原则

### 4.1 适用场景
- 儿童教育类 App / 小程序
- 英语学习产品界面
- 互动课件与动画
- 品牌周边与表情包

### 4.2 设计原则
1. **一致性**：所有视觉元素保持统一的描边规则和配色体系
2. **亲和力**：圆润造型 + 暖色调，营造友好、安全的视觉感受
3. **辨识度**：IP 形象具有独特记忆点，易于品牌传播
4. **延展性**：风格可延展至多种场景和载体
