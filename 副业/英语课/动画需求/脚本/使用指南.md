# 飞书文档批量导入脚本使用指南

## 概述

这是一个跨平台的 Node.js 脚本，用于批量将本地 Markdown 文件导入到飞书云空间，并自动移动到指定的 Wiki 知识库节点下。

## 前置条件

### 1. 安装 Node.js

脚本需要 Node.js 运行环境（版本 14.0 或更高）。

**检查是否已安装：**
```bash
node --version
```

如未安装，请前往 [Node.js 官网](https://nodejs.org/) 下载并安装。

### 2. 安装并配置飞书 CLI

确保已安装飞书 CLI 并完成认证配置：

```bash
# 检查飞书 CLI 是否已安装
lark-cli --version

# 检查认证状态
lark-cli auth status
```

如未安装，请参考飞书 CLI 安装指南：https://open.feishu.cn/document/no_class/mcp-archive/feishu-cli-installation-guide.md

## 快速开始

### 1. 准备 Markdown 文件

将需要导入的 Markdown 文件（`.md`）放在与脚本同级的目录中，或确保脚本可以通过相对路径访问到这些文件。

### 2. 编辑配置

打开 `batch-import.js`，修改文件顶部的配置区：

```javascript
// 配置区 ==========================================
// 目标 wiki 节点信息
const WIKI_TOKEN = 'Pkk5wr7YjiPBtekf2b2cIhj3neb';
const SPACE_ID = '7527253866397188115';

// 待导入的文件列表（相对于脚本所在目录）
const FILES = [
  '描红题.md',
  '情景对话.md',
  '闪卡题.md',
  '通用答题反馈.md',
  '通用loading.md',
  '涂色题答题页.md'
];
// =================================================
```

#### 配置参数说明

| 参数 | 说明 | 如何获取 |
|------|------|----------|
| `WIKI_TOKEN` | 目标 Wiki 节点 token | 从飞书 Wiki 链接中提取，如 `https://my.feishu.cn/wiki/Pkk5wr7YjiPBtekf2b2cIhj3neb` 中的 `Pkk5wr7YjiPBtekf2b2cIhj3neb` |
| `SPACE_ID` | Wiki 空间 ID | 使用命令获取：`lark-cli drive +inspect --url 'https://my.feishu.cn/wiki/<wiki_token>'` |
| `FILES` | 待导入的文件列表 | 填写相对于脚本所在目录的文件路径 |

### 3. 运行脚本

在终端中，进入脚本所在目录，执行：

```bash
node batch-import.js
```

## 脚本执行流程

脚本会自动完成以下步骤：

1. **导入文件**：使用 `lark-cli drive +import` 将 Markdown 文件导入为飞书在线文档（docx 格式）
2. **移动到 Wiki**：使用 `lark-cli wiki +move` 将导入的文档移动到目标 Wiki 节点下
3. **输出结果**：显示每个文件的导入状态和最终的 Wiki 链接

## 常见问题

### 1. 提示 "lark-cli: command not found"

**原因**：飞书 CLI 未安装或未添加到系统 PATH 中。

**解决方法**：
- 确认已安装飞书 CLI
- 检查 PATH 环境变量是否包含 npm 全局 bin 目录

### 2. 提示 "not configured"

**原因**：飞书 CLI 未完成配置。

**解决方法**：
```bash
lark-cli config init --new
```
按提示完成配置流程。

### 3. 提示 "permission denied"

**原因**：当前账号没有目标 Wiki 节点的写入权限。

**解决方法**：
- 联系知识库管理员，为你的账号添加编辑权限

### 4. 提示 "file not found"

**原因**：配置文件中的文件路径不正确或文件不存在。

**解决方法**：
- 确认文件路径相对于脚本所在目录是正确的
- 确认文件名拼写正确（注意中文文件名）

### 5. 导入后文档显示乱码

**原因**：Markdown 文件编码不是 UTF-8。

**解决方法**：
- 使用文本编辑器将文件转换为 UTF-8 编码后重新导入

## 注意事项

1. **API 限流防护**：脚本在每个文件操作之间自动添加 1 秒延迟，避免触发飞书 API 频率限制
2. **文件大小限制**：Markdown 文件导入为 docx 的大小上限为 20MB
3. **权限要求**：需要对目标 Wiki 节点有编辑权限
4. **网络要求**：执行脚本时需要保持网络连接正常
