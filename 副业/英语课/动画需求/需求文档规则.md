
1. **文件名**：按对应的 **UI 页面名称**命名（如 `正确反馈页.md`、`通用loading.md`），保持与 UI 设计稿一致，便于查找对应页面的动效。
2. **一级标题**：使用 `# 页面名 + 动画`（如 `# 正确反馈页动画`），明确文档归属页面。
3. **模块分组**：若页面内包含多个独立动效模块（如角色、粒子、文字），用二级标题 `## 模块名` 分隔，提高可读性。
4. **动效状态表格**：每个模块下一个表格，包含三列：
   - **状态名称**：英文标识 + 中文描述（如 `jump_entry（跳跃入场）`），状态名唯一且反映动效类型。
   - **触发条件**：明确描述何时触发（自动播放、用户操作、前序动画完成、同步触发等），避免歧义。
   - **动画描述**：用简洁的陈述句描述完整动效过程，包括运动轨迹、缓动类型、持续时间、伴随元素、色彩/数量等关键属性。
5. **状态顺序**：表格内按播放先后顺序排列（触发条件中的“完成之后”自然体现先后关系）。
6. **其他规则**：避免冗余描述，所有动效统一遵从该格式；若状态过多，可拆分多个表格或分组；保持全文件行文风格一致（如统一使用中文标点、中英文空格等）。
