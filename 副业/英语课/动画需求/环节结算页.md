## 一、环节完成横幅

![image.png](https://qhdob.oss-cn-chengdu.aliyuncs.com/assets/20260528205123.png)

### 1.1 黄色横幅

| 状态名称                    | 触发条件      | 动画描述                  |
| ----------------------- | --------- | --------------------- |
| banner\_slide\_in（横幅滑入） | 答题结束后自动触发 | 黄色箭头横幅从屏幕左右两侧同时滑入画面中央 |
| banner\_settle（横幅静止）    | 滑入完成后     | 横幅保持静止，作为背景和文字承载容器    |

### 1.2 卡皮巴拉角色

| 状态名称                | 触发条件          | 动画描述                            |
| ------------------- | ------------- | ------------------------------- |
| capybara\_jump（跃入）  | 与横幅滑入同步触发     | 卡皮巴拉从横幅下方弹跳跃入画面，双臂高举欢呼，身体伴随弹性效果 |
| capybara\_cheer（欢呼） | 跳跃完成后自动播放（循环） | 卡皮巴拉保持欢呼姿态，身体轻微弹跳，双臂可交替挥动       |

### 1.3 纸屑粒子

| 状态名称                  | 触发条件        | 动画描述              |
| --------------------- | ----------- | ----------------- |
| confetti\_burst（纸屑爆发） | 与卡皮巴拉跳跃同步触发 | 彩色纸屑从画面中心向四周抛物线散开 |

### 1.4 "环节完成"文字

| 状态名称            | 触发条件      | 动画描述    |
| --------------- | --------- | ------- |
| text\_pop（文字弹出） | 横幅滑入完成后触发 | 合适的出现效果 |
