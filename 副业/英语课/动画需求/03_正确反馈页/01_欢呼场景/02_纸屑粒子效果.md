# 纸屑粒子效果

## 状态列表

### burst（纸屑爆发）

**触发条件：** 用户回答正确时与欢呼动画同步触发

**动画描述：**

- 彩色小方块/小纸片从中心向四周散开
- 数量：15-25 个粒子
- 颜色：多种颜色随机分配
- 运动轨迹：抛物线运动，逐渐下落

**粒子设计要求：**

- 粒子数量：约 20 个
- 初始位置：动画中心点
- 运动范围：X轴随机 ±100px，Y轴下落 150-200px
- 旋转：0-360 度随机旋转
- 粒子形状：rectangle / circle
- 粒子尺寸：5px - 10px

**颜色方案：**

| 颜色编号 | 色值 | 用途 |
|----------|------|------|
| C-01 | #FF6B6B | 红色系 |
| C-02 | #4ECDC4 | 青色系 |
| C-03 | #45B7D1 | 蓝色系 |
| C-04 | #FFA07A | 橙色系 |
| C-05 | #98D8C8 | 绿色系 |
| C-06 | #FFD93D | 黄色系 |
| C-07 | #C9B1FF | 紫色系 |
