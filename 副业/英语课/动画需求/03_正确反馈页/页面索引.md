# 正确反馈页

## 页面描述

用户回答正确时触发的庆祝反馈动画

---

## 页面全局动画要求

| 项目 | 要求 |
|------|------|
| 触发条件 | 用户回答正确时触发 |
| 全屏遮罩 | 变暗 |
| 动画元素浮层 | 显示 |
| 帧率 | 所有动画保持 60fps |
| 资源格式 | 优先使用 Lottie/JSON 格式 |
| 图片资源 | PNG 透明背景 |
| 文件大小 | 单个动画文件不超过 500KB |
| 兼容性 | 支持 iOS/Android/Web |

---

## 资源清单汇总

| 资源名称 | 格式 | 用途 | 所属元素 |
|----------|------|------|----------|
| correct_jump | Lottie/MP4 | 欢呼跳跃动画 | 卡皮巴拉欢呼 |
| confetti_particles | Lottie | 纸屑散落效果 | 纸屑粒子效果 |
| combo_text_pop | CSS/Lottie | Combo文字弹出 | combo文字 |
