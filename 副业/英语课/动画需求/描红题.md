# 答题结算页

> 本页面动效适用于 A-Z 共 26 个字母，字母角色共用同一套动画
## 一、3D 字母角色动画

| 状态名称              | 触发条件        | 动画描述                                              |
| ----------------- | ----------- | ------------------------------------------------- |
| jump_entry（跳跃入场）  | 页面加载时自动播放   | 3D 字母角色从画面下方弹跳跃入中央，伴随弹性缓动（easeOutBack），持续时间约 0.6s |
| cheer_loop（欢呼循环）  | 跳跃入场完成后自动播放 | 角色双臂上下挥动，身体轻微左右摇摆，保持兴奋状态，持续约 1.5s~2s              |

## 二、彩纸粒子效果

| 状态名称                | 触发条件                    | 动画描述                                    |
| ------------------- | ----------------------- | --------------------------------------- |
| burst（彩纸爆发）         | 与欢呼循环（cheer_loop）同步循环播放 | 12~20 片彩色纸屑从角色中心向四周抛物线散开，随机分配颜色，伴随下落和淡出 |

# 新手引导

## 小手引导动画

| 状态名称                 | 触发条件           | 动画描述                                                                       |
| -------------------- | -------------- | -------------------------------------------------------------------------- |
| hand_appear（小手出场）    | 用户超过 5 秒未操作时触发 | 小手图标                                                                       |
| pen_trace（画笔描摹）      |                | 小手带动画笔沿预设笔画路径（字母当前笔画轨迹）匀速绘制，持续约 1.5 s~2 s，画笔在绘制区域留下对应颜色的笔迹效果，与用户实际操作时的笔迹一致 |
| hand_disappear（小手退场） | 画笔描摹完成后自动播放    | 小手在笔画终点处 0.3 s 内淡出（opacity 1→0）并缩小消失，笔迹保留在画面上                              |
| idle_hint（空闲提示）      | 用户继续未操作，动画循环播放 | 若用户仍未操作，间隔 2 s 后重复播放完整引导动画，直至用户开始绘制                                        |
