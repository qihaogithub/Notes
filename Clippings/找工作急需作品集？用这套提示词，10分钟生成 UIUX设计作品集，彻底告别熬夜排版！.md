## 一、AI 生成作品集

首先打开 ChatGPT，上传自己设计的 UI 界面，再复制下面这段提示词：

```markdown
我会上传一组 UI 设计图片，请基于这些图片帮我生成一套 Behance 风格的 UI/UX 作品集页面。要求：
1. 页面尺寸统一为 16:9 横版；
2. 风格参考 Behance 上高质量 UI/UX Case Study，具有专业作品集感；
3. 页面之间视觉语言统一（留白、字体、色彩、排版栅格一致）；
4. 结合我上传的 UI 图片内容来提取业务逻辑和 UX 流程；
5. 页面除了视觉展示，还要包含合理的 UX 框架与文案说明，包括：产品背景、业务目标、用户痛点、核心流程、信息架构、功能拆解、交互逻辑、视觉体系与设计系统；
6. 自动补全文案时必须合逻辑、简洁专业，贴合真实产品设计思考，不要编造夸张业务成果；
7. 不要做成宣传海报，不要花哨装饰，要像真正的 Case Study 页面。

请按照以下结构生成页面，并逐页输出每页内容的布局建议与最终效果图说明：

页面结构建议：
1. 【封面页】
   - 标题：项目名称
   - 副标题：产品类型 / 设计年份 / 关键词
   - 视觉关键 UI 展示
   - 简短一句话概括业务目标

2. 【产品背景 + 设计目标】
   - 为什么要设计这个产品？目标用户是谁？
   - 产品的业务场景与用户痛点总结
   - 设计目标与核心价值假设

3. 【用户分析 + 竞品/调研】
   - 用户角色（Persona）
   - 用户使用场景与典型问题
   - 核心用户需求及动机
   - 可用简单图表、流程图辅助说明

4. 【信息架构 + 交互流程】
   - 产品信息结构图
   - 主要用户任务流程图（如：登录 → 发现 → 聊天 → 发布）
   - 关键交互路径说明
   - 页面流程注释

5. 【核心界面展示页】
   - 重点展示 UI 图片中的首页 / 关键界面
   - 配合简短说明，解释核心功能与用户价值
   - 局部放大功能细节或交互细节

6. 【功能拆分与模块展示】
   - 提炼产品核心功能模块
   - 模块结构说明 + 视觉示意
   - 每个模块要有标题和简短说明

7. 【设计系统页】
   - 颜色规范、字体体系、图标与卡片样式展示
   - 组件规范说明
   - 保持统一视觉系统

8. 【整体界面整合页】
   - 设计全局示意图（多屏展示）
   - 可加入设备样机、局部切图、对齐栅格展示

9. 【总结页】
   - 设计成果总结
   - 个人思考 / 后续优化方向

10. 【谢谢页 / Thank You 页】
    - 作为整套作品集的最后一页
    - 页面文案可包含：“Thanks for watching” / “Thank You” / “谢谢观看”
```

## 二、修改文字内容

如果你对生成的内容不满意，想要修改，可以打开 Lovart，点击左上角的创建项目【+】按钮，把作品集页面拖进画布。图片可以放大变高清，也可以编辑文字。点击【编辑文字】后，直接修改文字内容即可。

到这里，一套 AI 生成的 UI/UX 作品集基本就完成了。

## 写在最后

AI 不是让我们完全不思考。它更像是帮你把最耗时间、最重复、最容易卡住的那部分先搭起来——比如页面结构、基础文案、视觉排版、作品集框架。这些以前很消耗精力的东西，现在可以先让 AI 帮你打个底。

但真正决定作品集质量的，还是你自己对项目的理解：你的界面为什么这么设计，用户痛点是什么，流程为什么这样走，哪些地方体现了你的设计判断。这些东西还是要自己认真看一遍、改一遍、调一遍。

所以我更建议大家把这套方法当成一个起点：先用 ChatGPT 快速生成作品集页面，再用 Lovart 修改文字和细节，最后根据自己的真实项目经历去润色内容。这样做出来的作品集，不只是快，也会更完整、更清楚。
