# 葱花火腿鸡蛋软饼

![[../img/01a10a262a017e20918ee37a3a4ddcc1.jpg]]

> 来源：[下厨房](https://www.xiachufang.com/recipe/107388674/)

## 食材

- 鸡蛋 2 个
- 中筋面粉 250g
- 火腿 半根
- 葱花 3 根
- 水 500g
- 盐 适量
- 五香粉 少许
- 鸡精 少许

## 步骤

1. 鸡蛋打散。
2. 加入面粉，搅拌成无颗粒状的面糊。
3. 再加入葱花火腿，搅拌均匀，加入清水。
4. 盐、五香粉、鸡精少许混合均匀。
5. 不粘锅烧热，刷一层油，放入一勺面糊快速摊平。
6. 煎制表面凝固起泡后喷一点油翻个面，继续烙一分钟。
7. 两面金黄即可装盘开吃。
