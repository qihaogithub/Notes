# 红烧猪脚炖土豆

## 食材

- 猪脚 500-700g
- 土豆 2 个
- 青椒 2 个
- 姜、葱、蒜、花椒、冰糖、豆瓣酱、火锅底料、生抽、蚝油、盐、料酒

## 步骤

### 核心思路（学会这逻辑，炖啥都香）

1. **先去腥再炖**：肉类必须焯水，去血沫、去腥味，汤清肉香不发腥。
2. **香料先炒香**：葱姜蒜、花椒、豆瓣酱、火锅料炒出红油，香味才够浓。
3. **肉先炒后压**：猪脚炒干表面、上糖色，口感更糯、更香、不柴。
4. **盐后放**：盐早放肉不易烂，最后放盐，肉质更软嫩。
5. **土豆后下更入味**：土豆煎过再烩，吸满汤汁，不烂不散。
6. **一锅到底少洗锅**：炒肉 → 煎土豆 → 回锅收汁，省事又香。

### 详细步骤

1. **猪脚焯水去腥**：冷水下锅，加姜片、料酒，煮沸撇去浮沫，用温水洗净备用。
2. **炒底料出红油**：锅中多放油，下姜、葱、蒜、花椒、冰糖炒香；再加豆瓣酱、火锅底料，小火炒出红油。
3. **猪脚炒至上色**：放入猪脚，大火翻炒至表面微焦、裹满酱料。
4. **调味增香**：加生抽、蚝油翻炒均匀，暂不放盐。
5. **高压锅压软烂**：加开水没过猪脚，煮沸后转入高压锅，上汽后压 12-15 分钟。
6. **土豆煎香更吸味**：原锅不用洗，放土豆煎至微黄，更香更定型。
7. **猪脚回锅烩土豆**：高压锅泄压后，连汤倒入锅中，与土豆一起焖煮 3-5 分钟入味。
8. **最后调味出锅**：尝味后再加盐，放入青椒、葱花翻匀即可。

### 举一反三通用公式

> 任意肉类（排骨/牛腩/鸡爪/鸡翅）+ 任意配菜（土豆/萝卜/腐竹/海带）

1. 焯水去腥
2. 炒香底料（姜葱蒜 + 豆瓣酱 + 火锅料/干辣椒）
3. 肉类炒干上色
4. 加生抽蚝油，不放盐
5. 高压锅/砂锅炖软
6. 配菜煎/炒后回锅收汁
7. 最后加盐、加青蒜/青椒出锅
