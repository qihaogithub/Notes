# AI 电子衣橱
**版本：** v1.0 (最终定稿版)
**适用平台：** 移动端 Web (PWA 模式，免安装)

---

## 一、 背景与目标

### 1.1 项目背景
太太拥有大量衣物，但在日常搭配中常面临“找不到衣服”或“不知道怎么搭”的问题。现有的衣橱 App 录入繁琐（需手动抠图、录入信息），且视觉美感不足。

### 1.2 项目目标
*   **极致简化录入：** 随手一拍，AI 完成抠图、打标、分类和美化。
*   **视觉统一美化：** 无论拍照环境如何，存入衣橱的都是精美的电商级平铺图。
*   **智能搭配引擎：** 基于自有库存，AI 提供每日穿搭建议。
*   **低成本运维：** 利用 Serverless 架构和按需计费的 API，实现近乎零成本的长期运行。

---

## 二、 用户场景

1.  **新衣入库：** 买了新衣服，随手在床上一拍。系统自动生成白底平铺图并识别出是“法式碎花裙”，自动归类到“连衣裙”分类。
2.  **今日穿搭建议：** 早晨起床，系统根据当地 15℃ 的天气，从衣橱里挑选出羊毛衫和牛仔裤，并生成一张模特穿搭示意图。
3.  **旧衣翻新：** 输入“我想搭配这件黑色西装”，AI 从现有库存中挑出最契合的内搭和下装。

---

## 三、 核心功能需求

### 3.1 智能录入引擎 (AI Input)
*   **多模式识别：** 
    *   支持“单件平铺照”或“真人上身照”。
    *   如果照片包含多件衣物（如套装），AI 需识别并引导用户拆分或自动拆分存为多个单品。
*   **自动处理流 (Pipeline)：**
    1.  **Vision 识别：** 调用 OpenAI 兼容的 Vision 模型，识别衣物属性（品类、颜色、季节、风格）。
    2.  **提示词构造：** AI 根据识别结果自动生成一段用于图像生成的 Prompt（例如：*“A high-quality flat lay photo of a beige cashmere sweater, studio lighting, white background”*）。
    3.  **平铺图生成：** 调用绘图 API 生成一张 1:1 的白底平铺图作为展示封面。
*   **自动归档：** 自动填充名称、标签，无需手动打字。

### 3.2 电子衣橱管理 (Digital Wardrobe)
*   **分类视图：** 顶部滑动导航（全部、上装、下装、裙装、鞋包、配饰）。
*   **瀑布流展示：** 统一的平铺图封面，视觉极度舒适。
*   **详情页：** 展示原始照片（留念）与 AI 平铺图，记录属性标签。

### 3.3 AI 穿搭助手 (AI Stylist)
*   **今日灵感：** 首页展示基于天气预报的穿搭组合。
*   **对话式搭配：** 用户可输入“明天去参加婚礼怎么穿？”，AI 返回单品组合。
*   **搭配美化图：** 选定组合后，AI 生成一张该组合的整体风格意境图或模特试穿图。

## 四、 实现方案

### 4.1 技术栈 (低成本组合)
*   **前端：** Next.js + Tailwind CSS (响应式设计，适配手机端)。
*   **部署：** Vercel (个人版免费)。
*   **数据库与存储：** Supabase (免费额度大，支持图片存储)。
*   **PWA：** 使用 `next-pwa` 插件，让网页可以“安装”到手机桌面，隐藏浏览器地址栏。

### 4.2 AI 接口策略 (统一 OpenAI 兼容格式)
项目需提供一个配置页面，支持设置：
1.  **基础 API 地址 (Base URL)**
2.  **API Key**
3.  **模型 ID 配置：**
    *   **Vision 模型：** 用于识别照片（推荐 `gpt-4o-mini` 或 `qwen-vl`，成本极低）。
    *   **Text 模型：** 用于搭配建议（推荐 `deepseek-chat` 或 `gpt-4o-mini`）。
    *   **Image 模型：** 用于生成平铺图（推荐兼容 OpenAI 格式的 `flux-schnell` 或 `dall-e-3`）。

### 4.3 核心数据结构 (Supabase)
```sql
-- 衣物单品表
CREATE TABLE clothes (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  original_image_url TEXT, -- 原始照片
  processed_image_url TEXT, -- AI 生成的平铺图
  category TEXT,           -- 分类
  tags JSONB,              -- 颜色、材质、季节等
  style_prompt TEXT,       -- AI 提取的描述词
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

*   开发“AI 穿搭助手”页面。
