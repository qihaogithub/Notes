使用 OpenCode JSON 配置。
你可以使用 JSON 配置文件来配置 OpenCode。

## [格式](https://opencode.ai/docs/config/#format)
OpenCode 支持 JSON 和 JSONC (带注释的 JSON) 格式。

```json
{ 
  "$schema": "https://opencode.ai/config.json",
  // 主题配置
  "theme": "opencode",
  "model": "anthropic/claude-3-5-sonnet",
  "autoupdate": true
}
```

## [位置](https://opencode.ai/docs/config/#locations)
你可以将配置文件放在多个位置，它们有不同的优先级。
**注意**：配置文件是合并的，而不是替换的。设置会从以下位置合并。较晚加载的配置仅在键冲突时覆盖较早的配置。

### [优先级顺序](https://opencode.ai/docs/config/#precedence-order)
配置源按以下顺序加载 (越晚加载的优先级越高)：
1. **远程配置** (`.well-known/opencode`) - 组织默认值
2. **全局配置** (`~/.config/opencode/opencode.json`) - 用户偏好
3. **自定义配置** (`OPENCODE_CONFIG` 环境变量) - 自定义覆盖
4. **项目配置** (项目中的 `opencode.json`) - 项目特定设置
5. **.opencode 目录** - 代理、命令、插件
6. **内联配置** (`OPENCODE_CONFIG_CONTENT` 环境变量) - 运行时覆盖

这意味着项目配置可以覆盖全局默认值，而全局配置可以覆盖组织的远程默认值。

### [远程](https://opencode.ai/docs/config/#remote)
组织可以通过 `.well-known/opencode` 端点提供默认配置。当你通过支持此功能的提供商进行身份验证时，它会自动获取。

### [全局](https://opencode.ai/docs/config/#global)
将全局配置放在 `~/.config/opencode/opencode.json`。用于设置主题、提供商或快捷键等用户范围的偏好。

### [按项目](https://opencode.ai/docs/config/#per-project)
在项目根目录添加 `opencode.json`。项目配置在标准配置文件中具有最高优先级。

### [自定义路径](https://opencode.ai/docs/config/#custom-path)
使用 `OPENCODE_CONFIG` 环境变量指定自定义配置文件路径。

### [自定义目录](https://opencode.ai/docs/config/#custom-directory)
使用 `OPENCODE_CONFIG_DIR` 环境变量指定自定义配置目录。该目录将用于搜索代理、命令、模式和插件。

## [架构 (Schema)](https://opencode.ai/docs/config/#schema)
配置文件有一个在 [opencode.ai/config.json](https://opencode.ai/config.json) 定义的架构。你的编辑器应该能够基于此进行验证和自动补全。

## [TUI 设置](https://opencode.ai/docs/config/#tui)
你可以通过 `tui` 选项配置 TUI 特定设置。
- `scroll_acceleration.enabled`: 启用 macOS 风格的滚动加速。
- `scroll_speed`: 自定义滚动速度倍数。
- `diff_style`: 控制差异渲染 ("auto", "stacked")。

## [服务器设置](https://opencode.ai/docs/config/#server)
通过 `server` 选项配置 `opencode serve` 和 `opencode web` 的服务器设置。
- `port`: 监听端口。
- `hostname`: 监听主机名。
- `mdns`: 启用 mDNS 服务发现。
- `cors`: 允许跨域请求的源。

## [工具管理](https://opencode.ai/docs/config/#tools)
通过 `tools` 选项管理 LLM 可使用的工具 (例如禁用写入或命令行执行)。

## [模型设置](https://opencode.ai/docs/config/#models)
通过 `provider`、`model` 和 `small_model` 选项配置模型。
- `small_model`: 用于轻量级任务 (如标题生成) 的独立模型。
- `timeout`: 请求超时时间 (毫秒)。
- `setCacheKey`: 确保为指定提供商设置缓存键。

### [亚马逊 Bedrock 特定选项](https://opencode.ai/docs/config/#amazon-bedrock)
- `region`: AWS 区域。
- `profile`: AWS 命名配置文件。
- `endpoint`: 自定义端点 URL。

## [主题](https://opencode.ai/docs/config/#themes)
配置你想要使用的主题。

## [代理 (Agents)](https://opencode.ai/docs/config/#agents)
通过 `agent` 选项配置针对特定任务的专业代理。

## [默认代理](https://opencode.ai/docs/config/#default-agent)
通过 `default_agent` 选项设置默认代理 (例如 "build" 或 "plan")。

## [分享设置](https://opencode.ai/docs/config/#sharing)
配置 `share` 功能：
- "manual": 允许通过命令手动分享 (默认)。
- "auto": 自动分享新对话。
- "disabled": 完全禁用分享。

## [自定义命令](https://opencode.ai/docs/config/#commands)
通过 `command` 选项配置用于重复性任务的自定义命令。

## [快捷键](https://opencode.ai/docs/config/#keybinds)
自定义快捷键。

## [自动更新](https://opencode.ai/docs/config/#autoupdate)
- `false`: 禁用自动更新。
- "notify": 仅通知新版本，不自动下载。

## [格式化程序](https://opencode.ai/docs/config/#formatters)
配置代码格式化工具 (如 Prettier)。

## [权限管理](https://opencode.ai/docs/config/#permissions)
默认情况下，OpenCode 允许所有操作无需显式批准。你可以通过 `permission` 选项更改此设置。

## [压缩 (Compaction)](https://opencode.ai/docs/config/#compaction)
- `auto`: 上下文满时自动压缩。
- `prune`: 移除旧的工具输出来节省 Token。

## [监听器 (Watcher)](https://opencode.ai/docs/config/#watcher)
配置文件监听器的忽略模式。

## [MCP 服务器](https://opencode.ai/docs/config/#mcp-servers)
配置你想要使用的 MCP 服务器。

## [插件](https://opencode.ai/docs/config/#plugins)
通过 `plugin` 选项加载 npm 插件。

## [自定义指令](https://opencode.ai/docs/config/#instructions)
通过 `instructions` 指定模型要遵循的自定义规则或指南文件。

## [禁用/启用提供商](https://opencode.ai/docs/config/#disabled-providers)
- `disabled_providers`: 明确禁用某些提供商。
- `enabled_providers`: 指定允许使用的提供商白名单。

## [实验性功能](https://opencode.ai/docs/config/#experimental)
处于开发中的不定期选项。使用时需谨慎。
