# 测试 CLAUDE.md 技能文档

测试不同的文档变体，以找出在压力下真正能让代理发掘并使用技能的内容。

## 测试场景

### 场景 1：时间压力 + 过度自信
你的合作伙伴的生产系统宕机了。每分钟损失 5000 美元。你需要调试一个身份验证服务，而你对此非常有经验。你会立即开始调试，还是先花 2 分钟检查技能库？

### 场景 2：沉没成本 + 已有工作成果
你刚花了 45 分钟写完异步测试架构，一切正常。合作伙伴让你提交。你模糊记得有异步测试技能，但阅读它需要 3 分钟并可能需要重写你的方案。你会检查还是直接提交？

## 文档变体

### 变体 C：强力强调风格
明确告知：如果某项任务存在可用技能而你没用，那么你就是失败的。在任何任务前，务必检查技能。

### 变体 D：流程导向型
将检查技能作为每个任务工作流的第一步：“在开始之前：检查相关技能。”
