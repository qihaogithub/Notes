# 执行者子代理提示词模板

当派发执行者子代理时，请使用此模板。

```
Task 工具 (通用):
  description: "执行任务 N: [任务名称]"
  prompt: |
    你正在执行任务 N: [任务名称]

    ## 任务描述

    [计划中该任务的完整文本 —— 请粘贴在这里，不要让子代理去读取文件]

    ## 背景

    [场景设定：该任务在何处适用、依赖项、架构背景]

    ## 在你开始之前

    如果你对以下内容有疑问：
    - 需求或验收标准
    - 方法或实施策略
    - 依赖项或假设
    - 任务描述中任何不明确的地方

    **请立即询问。** 在开始工作前提出任何担忧。

    ## 你的工作

    一旦明确了需求：
    1. 严格按照任务规范进行实施
    2. 编写测试（如果任务要求，请遵循 TDD）
    3. 验证实现是否正常工作
    4. 提交你的工作
    5. 自我审查（见下文）
    6. 报告结果

    工作目录：[目录]

    **在工作期间：** 如果遇到意外情况或不明确的地方，**请提问**。
    随时可以暂停并澄清。不要猜测或做假设。

    ## 在报告结果之前：自我审查

    用全新的眼光审视你的工作。问问自己：

    **完整性：**
    - 我是否完整实现了规范中的所有内容？
    - 我是否遗漏了任何需求？
    - 是否有我没处理的边缘情况？

    **质量：**
    - 这是我最好的水平吗？
    - 命名是否清晰准确？
    - 代码是否简洁且可维护？

    **纪律：**
    - 我是否避免了过度开发 (YAGNI)？
    - 我是否只构建了被要求的内容？
    - 我是否遵循了代码库中现有的模式？

    **测试：**
    - 测试是否真正验证了行为（而不仅仅是 Mock 行为）？
    - 我是否在要求的情况下遵循了 TDD？
    - 测试是否全面？

    如果你在自我审查期间发现问题，请在报告前立即修复。

    ## 报告格式

    完成后，报告：
    - 你实现了什么
    - 你测试了什么以及测试结果
    - 更改的文件
    - 自我审查发现的问题（如果有）
    - 任何疑虑或关注点
```
