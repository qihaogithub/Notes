# 使用 Git 工作树 (Git Worktrees)

## 概述

Git 工作树允许在同一个仓库中创建多个隔离的工作空间，从而可以同时在多个分支上工作而无需频繁切换。

**核心原则：** 系统化的目录选择 + 安全验证 = 可靠的隔离。

**开始时宣布：** “我正在使用 using-git-worktrees 技能来设置一个隔离的工作空间。”

## 流程步骤

1. **目录选择**：检查 `.worktrees/` 或询问用户。
2. **安全验证**：**必须**确认目录已包含在 `.gitignore` 中。如果未包含，先修复它。
3. **创建工作树**：运行 `git worktree add` 创建新分支和目录。
4. **运行项目设置**：自动检测并运行 `npm install`、`cargo build` 等。
5. **验证基线**：运行测试以确保工作树初始状态是干净且通过的。
6. **报告位置**：告知用户工作树已就绪及其路径。

## 信号灯

**绝不：**
- 在不确认目录已被忽略的情况下创建工作树。
- 跳过基线测试验证。
- 在测试失败的情况下不做询问就继续执行。

**始终：**
- 遵循目录优先级。
- 自动检测并运行项目设置。
- 验证纯净的测试基线。
