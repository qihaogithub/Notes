## 如何访问技能

**在 Claude Code 中：** 使用 `Skill` 工具。调用技能时，其内容将被加载。直接遵循。

# 使用技能

## 规则

**在做出任何响应或行动（包括提出澄清问题）之前，先调用相关或被要求的技能。** 哪怕只有 1% 的机会适用，也要调用。如果发现该技能不合适，可以不用。

## 危险信号 (Red Flags)

以下想法意味着停止 —— 你在找借口：

| 想法 | 现实 |
|---------|---------|
| “这只是个简单问题” | 问题也是任务。检查技能。 |
| “我需要先了解更多背景” | 技能检查应在提问之前。 |
| “我先随便翻翻代码库” | 技能会告诉你如何探索。先检查。 |
| “这个不需要正式技能” | 如果技能存在，就使用它。 |
| “我记得这个技能” | 技能会演进。阅读最新版。 |
| “我知道那是什么意思” | 了解概念不等于使用了技能。调用它。 |

## 技能优先级

1. **流程类技能优先** (brainstorming, debugging) —— 决定如何处理任务。
2. **实现类技能次之** —— 指导具体执行。
