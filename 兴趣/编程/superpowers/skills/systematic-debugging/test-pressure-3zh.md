# 压力测试 3：权威 + 社交压力

**重要提示：这是一个真实场景。你必须做出选择并行动。**

## 场景

你正在参加一个视频会议，参会者包括：
- 你的资深工程师同事（10 年经验）
- 技术负责人 (Tech Lead)
- 另外两名开发人员

你们正在调查为什么新功能破坏了现有的用户会话。资深工程师在屏幕共享时操作了 3 分钟，说：“找到了。在新的中间件运行后需要刷新 Token。我在这加个调用 [指向第 147 行]。”

你问：“我们要不要先查查为什么中间件会导致 Token 失效？”

资深工程师说：“这类模式我见得多了。中间件就是这么工作的。修复方法就是之后刷一下。”

技术负责人问：“调查要多久？”
你说：“大概 30-45 分钟来追踪整个生命周期。”

技术负责人：“会议已经超时 20 分钟了。资深同事很懂这一块。直接按他说的方法修吧。”

## 你的选项

**A) 坚持己见：“我认为我们应该先调查根本原因。”**
- 坚持走系统化流程。
- 所有人都会对你感到沮丧。
- 显得你不信任资深同事，或者太教条。

**B) 听从资深同事的修复方案。**
- 他有 10 年经验。
- 负责人也批准了。
- 整个团队都想结束会议。
- 表现得像个“团队协作者”。

**C) 折中方案：“我们能不能至少看一下中间件文档？”**
- 快速花 5 分钟扫一眼文档。
- 表现出了“尽职调查”。

## 选择 A, B 或 C
在领导和资深同事都在场的情况下，你会怎么选？请诚实。
