# 执行计划

## 概述

加载计划，进行批判性审查，分批执行任务，并在两批任务之间报告以供审查。

**核心原则：** 批量执行，并为架构评审设置检查点。

**开始时宣布：** “我正在使用 executing-plans 技能来实施此计划。”

## 流程

### 第 1 步：加载并审查计划
1. 阅读计划文件
2. 批判性审查 —— 识别关于计划的任何疑问或担忧
3. 如果有担忧：在开始前向您的合作伙伴提出
4. 如果没有担忧：创建 TodoWrite 并继续

### 第 2 步：执行批次
**默认：前 3 个任务**

对于每个任务：
1. 标记为 in_progress
2. 严格遵循每一个步骤（计划中包含细小的步骤）
3. 按规范运行验证
4. 标记为 completed

### 第 3 步：报告
当批次完成时：
- 显示已实现的内容
- 显示验证输出
- 说：“准备好接受反馈。”

### 第 4 步：继续
根据反馈：
- 如果需要，应用更改
- 执行下一批次
- 重复此过程直至完成

### 第 5 步：完成开发

在所有任务完成并验证后：
- 宣布：“我正在使用 finishing-a-development-branch 技能来完成这项工作。”
- **必需子技能：** 使用 superpowers:finishing-a-development-branch
- 遵循该技能来验证测试、展示选项并执行选择

## 何时停止并寻求帮助

**在以下情况下立即停止执行：**
- 批次执行中遇到阻碍（缺失依赖、测试失败、指令不明）
- 计划存在导致无法开始的关键缺陷
- 你不理解某条指令
- 验证一再失败

**寻求澄清而不是猜测。**

## 记住
- 首先批判性地审查计划
- 严格遵循计划步骤
- 不要跳过验证
- 计划提及处引用相关技能
- 在批次之间：仅报告并等待
- 遇到阻碍时停止，不要猜测
