# 🚀 macOS 钉钉日志富文本导出工具 - 需求文档 (Markdown 版)

## 1. 文档概述
本文档明确基于 Python 开发的 macOS 钉钉日志导出工具的核心需求、技术栈、交互流程及编码规范，工具核心目标是将钉钉日志的富文本内容（HTML 格式）转换为高质量 Markdown 文件并保存。

## 2. 核心目标
- 运行环境：macOS 系统（适配 Retina 屏幕坐标系）。
- 核心功能：遍历钉钉日志列表，模拟鼠标/键盘操作复制日志内容，读取剪贴板中的 HTML 富文本数据，转换为 Markdown 格式（保留加粗、标题层级、链接等）并保存。
- 降级处理：若剪贴板无 HTML 数据，自动降级保存纯文本内容。

## 3. 技术栈与依赖
| 技术类别   | 具体依赖/工具                 | 用途说明                                 |
| ---------- | ----------------------------- | ---------------------------------------- |
| 交互控制   | pyautogui                     | 模拟鼠标点击、键盘快捷键、屏幕滚动       |
| 剪贴板读取 | AppKit/pyobjc-framework-Cocoa | 读取 macOS 原生剪贴板的 public.html 数据 |
| 格式转换   | markdownify                   | 将 HTML 转换为 ATX 格式的 Markdown       |
| 运行环境   | Python 3.x + macOS            | 脚本执行基础环境                         |

## 4. 核心交互流程
### 4.1 初始化与定位（半自动，需人工配合）
1. 脚本启动后，终端提示：「请在 5 秒内将鼠标悬停在第一条日志的中心位置，不要移动」；
2. 倒计时结束，脚本记录鼠标坐标 (StartX, StartY)；
3. 终端询问用户：
   - 需抓取的日志数量（示例：10）；
   - 日志列表项的大致高度（像素，默认 80）。

### 4.2 自动化循环（核心执行逻辑）
脚本按用户输入的日志数量执行循环（`for i in range(count)`），步骤如下：
| 步骤 | 操作内容                                                     | 等待时间                 |
| ---- | ------------------------------------------------------------ | ------------------------ |
| 1    | 计算点击坐标：CurrentY = StartY + (i * ItemHeight)；<br>若坐标超出可视范围，执行滚动操作并重置 Y 轴偏移；<br>移动鼠标至 (StartX, CurrentY) 并点击 | 1.5 秒（等待内容加载）   |
| 2    | 鼠标移至右侧内容区点击聚焦；<br>执行 Command+A（全选）→ Command+C（复制） | 0.5 秒（等待剪贴板写入） |
| 3    | 调用原生接口读取剪贴板 public.html 数据；<br>有 HTML 则转换为 Markdown，无则降级用纯文本 | -                        |
| 4    | 提取文本首行作为文件名（去除非法字符）；<br>保存至桌面 DingTalk_Logs 文件夹 | -                        |

## 5. 关键技术要点
### 5.1 核心变更说明
需读取剪贴板的 **HTML 数据** 而非纯文本（因 HTML 粘贴到 Typora 可完美保留格式，是实现高质量 Markdown 的核心）。

### 5.2 剪贴板读取核心要求
- 必须使用 AppKit 的 NSPasteboard 接口，禁止使用 pyperclip（无法获取 HTML 数据）；
- 需实现函数 `get_clipboard_html()`，逻辑：
  1. 调用 `NSPasteboard.generalPasteboard()` 获取系统剪贴板；
  2. 读取 `public.html` 类型数据；
  3. 成功则返回 HTML 字符串，失败则返回 None。
