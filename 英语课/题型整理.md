背景：一个英语学习 APP 的题型设计。
常规题目分为题干和作答两部分

## 题干类型
文字、图片、视频、 音频、闪卡

## 作答类型
- `开口`：调用设备麦克风采集语音。系统实时降噪并转为音频流进行比对。
- `点选`：点击屏幕上的选项、按钮或特定区域完成作答。支持单选/多选。
- `拖拽`：长按选项并拖动至目标空位或区域，松手确认。支持吸附对齐与错误回弹。
- `涂鸦`：在透明画布上通过手指/触控笔绘制。支持撤销、清空、笔触粗细调节。
- `连线`：点击左侧起点与右侧终点，或长按拖拽绘制连线。支持交叉避让与自动吸附。

### 🎤 开口类
**录音交互：**
- **状态**：`默认` → `说话中` → `结束`
- **触发机制**：
    - **手动触发**：`默认` 状态下支持用户点击控件激活录音。
    - **自动激活**：题干（文字/语音/视频）播放完毕后，控件自动激活，用户可直接开口。
- **录音控制**：
    - **倒计时自动结束**：`说话中` 状态伴随倒计时，归零后自动转入 `结束`。
    - **手动提前结束**：录音过程中用户可随时点击提前结束。
- **结束态操作**：进入 `结束` 状态后，支持回放已录语音，或点击「重新开始」重置录制。

#### 语音问答     
- **玩法简介**：题干文字和音频，进入页面先播放题干语音，之后提示用户开口，用户开口后，判断对错，可重试 3 次，答对或达到次数则结束显示题目结算页。
- **状态机**：`待机` → [播放题干] → `录音准备` → [长按] → `录音中` → [松开/超时] → `AI处理` → [完成] → `结果展示` → [重试/下一题] → `待机`

#### 绘本配音
- **玩法简介**：动画播放至留白处自动暂停并高亮角色气泡；底部显示角色头像与录音进度条；支持录制中途打断；提交后自动混音并全屏播放完整配音；支持多角色循环录制。
- **状态机**：`动画播放` → [遇留白] → `角色提示` → [长按录制] → `混音处理` → [完成] → `合成播放` → [确认/重录] → `结算` → `完成`

#### 闪卡跟读
- **玩法简介**：卡片展示图片，用户看图朗读单词，朗读后卡片反转，显示英标等信息，然后移入新卡片，同一道题最多 4 个卡片。
-  **交互**：
    - **首题引导**：首次进入播放3秒手指动画+语音提示，指导用户如何使用语音答题按钮。
      ![image.png](https://qhdob.oss-cn-chengdu.aliyuncs.com/assets/20260422233635.png)

    - **录音反馈**：控件实时显示波形动效与倒计时进度条（默认5-8秒可配），超时自动切断并触发判定。
      ![image.png](https://qhdob.oss-cn-chengdu.aliyuncs.com/assets/20260422233727.png)

    - **正误反馈**：
        - ✅ **正确**：卡片3D翻转（背面展示音标/释义），触发礼花动效，麦克风按钮转绿。支持点击对勾旁边音频按钮重听用户录音，点击翻转后卡片播放标准发音。
          ![image.png](https://qhdob.oss-cn-chengdu.aliyuncs.com/assets/20260422233822.png)

        - ❌ **错误**：卡片左右抖动（2次），麦克风按钮转红+破碎图标。提示“再试一次”，错误两次则跳过。

    - **动效衔接**：结算或切换时，当前卡片左移，新卡片从右侧飞入（`ease-out` 曲线）。
      ![image.png](https://qhdob.oss-cn-chengdu.aliyuncs.com/assets/20260422234204.png)

    - **文本适配**：单词/短语长度自适应。超阈值自动等比缩小字号（最小字号）

- **⚙️ 核心业务逻辑**：
    - **评分标准**：对接AI语音评测引擎（流利度/准确度/完整度）。阈值可后台配置（如≥80分判对）。
    - **重试机制**：单题最多重试3次。3次失败则展示正确答案，自动打标“需复习”，顺延至下一题。
    - **防刷/环境校验**：录音前前置检测麦克风权限；环境底噪过高时提示“请在安静环境录制”；支持录音中途取消。
    - **连击激励**：连续答对3题触发Combo特效并奖励学习币/积分，提升模块粘性。
- **状态机**：`待读` → [点击录音] → `录音中` → [超时/提交] → `AI判定` → [正确] → `成功反馈` / [错误] → `错误反馈` → [重试/下一题] → `结果展示` → [继续] → `新卡飞入` → `待读`

#### 情景对话
- **玩法简介**：AI 语音播放时头像伴随口型动效；用户录音支持实时语音转文字浮层显示；流式响应期间显示“思考中”；对话结束生成交际维度雷达图（流利度/准确度/逻辑）。
- **状态机**：`AI提问` → [播放结束] → `用户输入` → [提交] → `流式响应` → [生成下一句] → `上下文更新` → 循环 → [触发结束] → `总结评分` → `完成`

### 🖱️ 点选类
#### 选择题
- **玩法简介**：选项点击伴随轻微缩放与边框高亮；支持单选/多选明确标识；提交后正确项标绿✅，错误项标红❌并伴随微震；解析面板支持滑动展开/收起，错题自动加入收藏夹。
- **状态机**：`待选` → [点击选项] → `已选中` → [点击确认] → `校验反馈` → [查看解析] → `解析展示` → [下一题] → `待选`

#### 找茬题
- **玩法简介**：双图并排或上下滑动对比；点击正确差异点触发绿色圆圈描边+“叮”音效；错误点击扣除机会并短暂红框提示；剩余次数/倒计时常驻顶部；全对触发全屏撒花动画。
- **状态机**：`观察中` → [点击画布] → `判定中` → [正确] → `已标记` / [错误] → `扣次提示` → [次数归零/全对] → `结算触发` → [下一题] → `观察中`

### 🤏 拖拽类
#### 拖拽填空题
- **玩法简介**：词块拖拽时放大 1.1 倍并半透明遮罩；接近目标空位显示吸附预览框与阴影；错误放置触发回弹动画+震动；正确放置锁定并变色；支持长按词块临时查看释义。
- **状态机**：`待拖拽` → [长按词块] → `拖拽中` → [松手] → `放置判定` → [吸附成功] → `已填入` / [失败] → `回弹重置` → [填满] → `校验反馈` → `完成`

### 🎨 涂鸦类
#### 描红题
- **玩法简介**：提供虚线引导与起笔点指示箭头；书写时笔迹自动贴合轨迹并实时纠偏；支持三指撤销、双指清空；提交后 AI 比对笔画顺序与结构覆盖率，低分显示正确书写动画。
- **状态机**：`提示展示` → [触碰起笔] → `书写中` → [提笔完成] → `笔迹判定` → [结构合格] → `评分通过` / [不合格] → `重写提示` → `完成`

#### 涂色题
- **玩法简介**：色板底部常驻，点击拾色器后显示当前颜色预览；点击封闭区域或长按拖动填充，内置防溢出算法；已填色区域显示色块名称英文浮层；提交后生成完整插画并播放关联单词发音。
- **状态机**：`线稿展示` → [选择颜色] → `选色中` → [点击/拖动] → `填色中` → [区域填满] → `填充完成` → [提交] → `校验展示` → `完成`

### 🔗 连线类
#### 连线题
- **玩法简介**：左右元素悬停时显示连接桩；点击起点拖动绘制贝塞尔曲线，终点区域高亮提示；连错显示红色虚线并支持点击线段末端擦除；正确连线变实线加锁；全对后路径依次流光高亮。
- **状态机**：`待连线` → [点击起点] → `连线中` → [连接终点] → `配对判定` → [正确] → `已锁定` / [错误] → `断线擦除` → [全部完成] → `路径动画` → `结算`
