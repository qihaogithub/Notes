背景：一个英语学习 APP 的题型设计。
常规题目分为题干和作答两部分

## 题干类型
文字、图片、视频、 音频、闪卡

## 作答类型
- `开口`：调用设备麦克风采集语音。系统实时降噪并转为音频流进行比对。
- `点选`：点击屏幕上的选项、按钮或特定区域完成作答。支持单选/多选。
- `拖拽`：长按选项并拖动至目标空位或区域，松手确认。支持吸附对齐与错误回弹。
- `涂鸦`：在透明画布上通过手指/触控笔绘制。支持撤销、清空、笔触粗细调节。
- `连线`：点击左侧起点与右侧终点，或长按拖拽绘制连线。支持交叉避让与自动吸附。

### 🎤 开口类
**录音交互：**
- **状态**：`默认` → `说话中` → `结束`
- **触发机制**：
    - **手动触发**：`默认` 状态下支持用户点击控件激活录音。
    - **自动激活**：题干（文字/语音/视频）播放完毕后，控件自动激活，用户可直接开口。
- **录音控制**：
    - **倒计时自动结束**：`说话中` 状态伴随倒计时，归零后自动转入 `结束`。
    - **手动提前结束**：录音过程中用户可随时点击提前结束。
- **结束态操作**：进入 `结束` 状态后，支持回放已录语音，或点击「重新开始」重置录制。

#### 语音跟读
- **玩法简介**：播放视频，配置开口时间节点，到达节点暂停视频，提示用户跟读，跟读后判断对对错，可重试 3 次，答对或达到次数则跳过继续播放视频。
- **状态机**：

#### 语音问答     
- **玩法简介**：题干文字和音频，进入页面先播放题干语音，之后提示用户开口，用户开口后，判断对错，可重试 3 次，答对或达到次数则结束显示题目结算页。
- **状态机**：`待机` → [播放题干] → `录音准备` → [长按] → `录音中` → [松开/超时] → `AI处理` → [完成] → `结果展示` → [重试/下一题] → `待机`

#### 绘本配音
- **玩法简介**：动画播放至留白处自动暂停并高亮角色气泡；底部显示角色头像与录音进度条；支持录制中途打断；提交后自动混音并全屏播放完整配音；支持多角色循环录制。
- **状态机**：`动画播放` → [遇留白] → `角色提示` → [长按录制] → `混音处理` → [完成] → `合成播放` → [确认/重录] → `结算` → `完成`

#### 闪卡跟读
- **玩法简介**：卡片展示图片，用户看图朗读单词，朗读后卡片反转，显示英标等信息，然后移入新卡片，同一道题最多 4 个卡片。

#### 情景对话
- **玩法简介**：AI 语音播放时头像伴随口型动效；用户录音支持实时语音转文字浮层显示；流式响应期间显示“思考中”；对话结束生成交际维度雷达图（流利度/准确度/逻辑）。
- **状态机**：`AI提问` → [播放结束] → `用户输入` → [提交] → `流式响应` → [生成下一句] → `上下文更新` → 循环 → [触发结束] → `总结评分` → `完成`

### 🖱️ 点选类
#### 选择题
- **玩法简介**：选项点击伴随轻微缩放与边框高亮；支持单选/多选明确标识；提交后正确项标绿✅，错误项标红❌并伴随微震；解析面板支持滑动展开/收起，错题自动加入收藏夹。
- **状态机**：`待选` → [点击选项] → `已选中` → [点击确认] → `校验反馈` → [查看解析] → `解析展示` → [下一题] → `待选`

#### 找茬题
- **玩法简介**：题干文本音频组合，标记用户已经找到几个。框只能是方形，配置位置，背景是zheng

### 🤏 拖拽类
#### 拖拽填空题
- **玩法简介**：词块拖拽时放大 1.1 倍并半透明遮罩；接近目标空位显示吸附预览框与阴影；错误放置触发回弹动画+震动；正确放置锁定并变色；支持长按词块临时查看释义。
- **状态机**：`待拖拽` → [长按词块] → `拖拽中` → [松手] → `放置判定` → [吸附成功] → `已填入` / [失败] → `回弹重置` → [填满] → `校验反馈` → `完成`

### 🎨 涂鸦类
#### 描红题
- **玩法简介**：提供虚线引导与起笔点指示箭头；书写时笔迹自动贴合轨迹并实时纠偏；支持三指撤销、双指清空；提交后 AI 比对笔画顺序与结构覆盖率，低分显示正确书写动画。
- **状态机**：`提示展示` → [触碰起笔] → `书写中` → [提笔完成] → `笔迹判定` → [结构合格] → `评分通过` / [不合格] → `重写提示` → `完成`

#### 涂色题
- **玩法简介**：每次涂一个部位，涂完判对，错误超过三次则跳过。题干文字和音频，涂色体没有 AI。
### 🔗 连线类
#### 连线题
- **玩法简介**：
- 连线题 AI 可以缩小和正常大小样式
- 第一排可连第二排可连第三排，全部连完才判对。
- 连一个就判对一个。
- 最多 4 列，最多 4 行。
- 选项只能是一种类型，不能文字和语音一起。
