# 🎨 互动组件：听指令涂色 (Listen & Color)

## 一、 功能简介 (Function Overview)
本组件是一款以**“听力理解+色彩认知+精细动作”**为核心教育目标的互动题型。
*   **教育目标**：考察儿童对英语（或双语）颜色词汇、身体部位/物品词汇的听音理解能力，同时锻炼手眼协调与指令跟随能力。
*   **核心玩法**：系统给出多步涂色指令（语音+文本），儿童需要在右侧固定色板中选取正确颜色，并点击画布中对应的空白区域进行上色。涂对进入下一步，连续涂错触发强提示。

---

## 二、 交互逻辑 (Interaction Logic)

### 整体流程
加载题目 ➔ 播放题干语音 1 ➔ 用户选色 ➔ 用户点击区域 ➔ 判定对错 ➔播放题干语音2 ➔ …➔题目完成。

### 交互状态说明
#### 初始状态
*   **画面**：展示未上色（或部分上色）的线稿图案。
*   **题干**：上方文本框展示当前步骤指令，同步自动播放对应的音频。
*   **画笔**：默认不选中任何颜色，画笔笔头为灰色状态。
![image.png](https://qhdob.oss-cn-chengdu.aliyuncs.com/assets/20260426185543.png)

#### 选色操作
*   **触发**：点击右侧 10 色色板中的任意颜色球。
*   **反馈**：
    *   **颜色球**：切换为选中状态。
    *   **画笔**：右下角画笔的笔刷前端颜色，立刻变为当前选中的颜色，作为明确的视觉暗示。

#### 3. 涂色判定 (Coloring & Validation)
用户选中颜色后，点击图案上的任意可交互区域，触发判定：

*   ✅ **涂对（选对颜色 且 点对部位）**
    *   **视觉反馈**：对应部位瞬间/平滑填充正确的颜色。触发 Combo 连击动效（如图片右上角 `Combo x8`）。
    *   **听觉反馈**：播放“正确提示音效（如 Ding~）”。
    *   **流程推进**：自动切换当前题干文本，并播放**下一个**题干语音指令。

*   ❌ **涂错（选错颜色 或 点错部位）**
    *   **视觉反馈**：被点击的图案部位不上色，图案整体（或被点击部位）触发“左右抖动”动效（时长约 0.3 s）。
    *   **听觉反馈**：播放“错误提示音效（如 Boing~）” + 容错语音提示（“不对哦，再想想吧”）。
    *   **计数器**：该步骤的错误次数 `+1`。

#### 4. 辅助提示机制 (Hint System)
*   **触发条件**：当**当前步骤**错误次数达到 **3 次** 时触发。
*   **听觉提示**：中断默认错误音，播放强提示语音（例：“苹果是红色的 / The apple is red”）。
*   **视觉提示（高光闪烁）**：目标部位会自动填充正确颜色 ➔ 消失变回线稿 ➔ 再填充 ➔ 再消失，持续闪烁 **3 秒**（呼吸灯频率），引导儿童点击该区域。在此期间儿童仍可操作。

## 三、 UI 与适配规范 (UI & Adaptation Guidelines)

作为兼顾儿童心理学的视觉设计，UI 需遵循“色彩明快、图形圆润、聚焦内容”的原则。

### 3.1 视觉风格 (Visual Style)
*   **整体氛围**：手账本/画板风格，背景采用低饱和度的暖黄色网格或纸张纹理，保护视力且不喧宾夺主。
*   **组件质感**：
    *   画板边框：圆润的木质/塑料质感，带轻微投影体现层级。
    *   颜色球：立体糖果质感/水滴质感。选中时通过内部阴影(`inner shadow`)表现出被按下的物理反馈（见原型左下角切图）。
*   **文字排版**：题干文字使用圆体或适合儿童阅读的无衬线黑体，字号需满足 iPad 端距离 40 cm 清晰可读（建议至少 `24pt/32px`）。

### 3.2 动效规范 (Animation Specs)
*   **画笔变色**：无延迟的硬切换，或 `0.15s` 的快速颜色渐变过渡。
*   **错误抖动**：CSS `Transform: translateX`。关键帧：`0px -> -8px -> 8px -> -6px -> 6px -> 0px`，时长 `0.3s`。
*   **Combo 动效**：弹性放大（`Scale 0 -> 1.2 -> 1.0`），伴随星星/纸屑粒子飞出，停留 `1.5s` 后渐隐。
*   **提示闪烁**：透明度渐变。`Opacity 0% -> 100% -> 0%`，周期为 `0.8s`，循环执行至多 3 秒。

### 3.3 屏幕适配 (Responsiveness)
*   **基准分辨率**：以 iPad 横屏 `1024x768` 或 `1366x1024` 为基准设计。
*   **安全区域**：避开异形屏刘海和底部 Home Indicator。
*   **自适应策略**：
    *   **顶部栏**（关闭按钮、进度条）：锚点在顶部，左右外扩或居中。
    *   **画板与色板**：作为一个整体 Group 居中显示，在更宽的屏幕（如比例 16:9）上，左右两侧露出更多背景图案。图案本身不可拉伸变形。
    *   **热区设定**：儿童手指较粗，所有颜色球和关闭按钮的点击热区需向外扩大至少 `10px`，SVG 填色区域如果面积太小，需在代码层扩大其不可见点击热区。

## 四、 后台配置 (Backend Configuration / CMS)

为了让教研老师能高效地产出此类题目，后台需要提供结构化的配置表单。

### 4.1 全局素材配置
*   **底图/线稿素材**：上传完整的底图图层和待上色的 SVG 线稿（注：需严格要求美术将可上色区域拆分为独立的 SVG Path 或带有 ID 的图层，以便代码读取）。
*   **调色盘**：虽然固定为 10 色，但后台可显示这 10 种颜色的 Hex 码（支持未来扩展）。默认色卡为：红、橙、黄、浅绿、天蓝、粉、棕、肉色、黑、白。

### 4.2 题干步骤配置 (支持增删改排序)
每道大题下支持配置 `N` 个步骤（如先涂身体，再涂苹果）。每个步骤需配置以下字段：

| 字段名称 | 类型 | 说明 |
| :--- | :--- | :--- |
| **步骤序号** | Number | 决定涂色的先后顺序（例如 1, 2, 3）。 |
| **目标区域 ID** | String | 绑定 SVG 图片中对应区块的 ID（如 `path_body`, `path_apple`）。 |
| **目标颜色** | Dropdown | 从 10 色列表中选择该部位对应的正确颜色。 |
| **题干文本** | String | 展示在顶部的提示文字，支持中英双语（如：“卡皮巴拉的身体是什么颜色？”）。 |
| **题干音频** | Audio | 对应当前题干的语音文件 `.mp3` / `.wav`。 |
| **错误 3 次提示音频**| Audio | 触发辅助提示时的特定语音（如：“苹果是红色的”）。 |

### 4.3 容错与通用配置
*   **通用错误语音**：上传音频（“不对哦，再想想吧”），系统默认调用。
*   **错误阈值**：默认 `3` 次触发强提示（建议做成可配数字，方便后期做难度分级调整）。

---
*💡 **产品经理寄语**：此题型不仅是在考察英语，更是在建立儿童的自信心。错误时的抖动不仅是提示，也是一种“小调皮”的互动；3 次之后的强引导确保了没有一个孩子会被卡在这一关而产生挫败感。开发时请务必关注音效的无延迟播放和涂色瞬间的丝滑感。*
