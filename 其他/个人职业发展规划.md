
## 1. 背景与现状
- 年龄：31 岁，当前岗位：儿童教育行业 UI 设计师
- 担忧：互联网行业下行，担心被裁员后找不到工作
- 核心诉求：制定预防性规划，应对不确定性
- 从业背景：2017 年毕业起从事 UI 设计，经验丰富但非专家水平，技能合格不出彩

## 2. 职业资产盘点
### 2.1 显性技能
| 能力项 | 自评 | 亮点 |
|--------|------|------|
| 业务场景理解力（儿童/教育） | 基本了解 | 熟悉家长+儿童双重交互需求 |
| 规范与工程提效 | 可搭建组件库 | 理解技术边界，沟通成本低 |
| 复杂链路设计落地 | 可独立负责完整模块 | 交互+视觉兼顾，但视觉表现力一般 |
| 技术边界理解 | 优于多数同事 | 清楚实现难度，开发还原度高 |

### 2.2 可迁移能力
- 沟通能力：自评一般（需进一步评估）
- 问题解决：能独立处理复杂模块
- 快速学习：愿意学 AI 编程等新工具

### 2.3 行业资源与人脉
- 近期获得前同事介绍的 UI 兼职（非刻意积累，但证明“靠谱”可带来机会）
- 目前人脉网较窄，有待主动经营

## 3. 路径探索（2026 年版本）
### 路径 A：垂直深耕（原行业+原岗位）
- **现状**：能力停滞，公司上升空间有限
- **趋势**：2026 年儿童教育设计正从“扁平静态内容”转向“AI 个性化微交互”与“高沉浸感游戏化学习”
- **破局点**：钻研 **低龄儿童的无障碍/低认知门槛交互设计** + **利用微交互提高儿童学习专注度**。这需要加深对儿童心理学和交互行为学的理解，而非视觉表现力——正是年轻设计师的盲区

### 路径 B：横向跨界（新行业+原岗位 / 原行业+新岗位）
- **现状**：视野窄，不清楚如何跨入新行业
- **策略**：保留一个变量，改变另一个变量——**新行业 + 原岗位**
- **破局点**：拥有 9 年 UI 设计经验+高开发还原度+组件库搭建能力。2026 年智能硬件、新能源汽车车载屏、大健康、工业软件等传统行业正加速数字化，极度缺乏“懂技术边界、设计规范严谨”的 UI 设计师。可将视线从纯互联网 APP 转向实体/半实体行业

### 路径 C：轻资产尝试（自由职业 / 兼职 / 顾问）
- **现状**：已有零星兼职，但仅限本职
- **策略**：将现有“UI 设计兼职”做到极致，借此积累**独立交付、直接面对客户**的商务和项目管理经验，不必急于开辟新变现途径

## 4. 行动引擎（持续更新）
### 4.1 财务安全（长期）
- 高房贷、车贷、育儿开支，无存款 → 仅靠裁员赔偿（约 6 个月）作为安全垫
- 目标：每月强制储蓄少量（100 元起步），积累紧急备用金
- **心理意义**：在极度焦虑时，强制存钱的心理安慰作用远大于实际金额。每天/周看着“绝对不能动的备用金”账户金额变大，能有效降低对“明天就被裁员”的恐慌

### 4.2 技能提升（本月开始）
- [ ] **AI 提效 → Designer-Builder**：使用 v 0.dev 或 bolt.new 等工具，将 Figma 设计稿转化为可运行的 React/Vue 组件代码。目标：独立交付“设计图+前端静态代码”的完整包，提升交付效率和性价比
- [ ] **作品集整理**：每半年更新一次，打破拖延（设定截止日，如 2026 年底前完成初版）

### 4.3 人脉维系（持续）
- [ ] 梳理 5-10 位前同事/领导，记录联系方式、近期动态、**他们当前所在的行业和公司**
- [ ] 每月主动对朋友圈的行业动态进行言之有物的专业评论（比群发祝福更有效）
- [ ] 作品集完成后发朋友圈，暗示可接兼职

### 4.4 认知拓展（每季度）
- [ ] 阅读行业报告 / 关注儿童教育+设计趋势
- [ ] 尝试在站酷/ Medium 等平台输出专业文章（建立个人品牌）

### 4.5 月度聚焦（2026 年 5 月 MVP）
本月聚焦两项最容易启动的待办：
- [ ] **AI 提效尝试**：用 AI 辅助工具解决一个工作或兼职中的小提效问题（如 Midjourney 生成儿童图标插画，或 AI 快速分析竞品设计规范）
- [ ] **人脉清单建立**：在微信里筛选并记录下 **5 位**合作愉快、专业靠谱、且当前在不同公司发展的前同事（暂不联系，只记名字和岗位）
